今日结论

  1. 今天确认 2 篇严格新增、真正把 JEPA 用于下游控制的论文。 Temporal-Distance JEPA 于 2026-07-28 06:38:16 UTC 提交，在 LeWM 上学习有方向的时间距离并把它接入 latent MPC；INTACT 于 2026-07-28 17:59:40 UTC 提交，在 LeWM 表示内把当前—目标 latent 位移直接映射为动作分布。两篇都不只是 related-work 引用。
  2. 它们瞄准同一个“训练—规划接口裂缝”，却给出相反方向的答案。 TD-JEPA 保留 CEM/iCEM 搜索，认为 JEPA 缺的是一个从示范轨迹中学出的 plan cost；INTACT 则联合学习 goal-intent→action 接口，让世界模型默认直接出动作，只把小规模搜索留作可选验证。TD-JEPA 原始 PDF｜INTACT 方法与控制流程
  3. TD-JEPA 的最强正证据是同协议四任务比较，但其主结果仍低估了训练随机性。 在固定 checkpoint、固定 50-episode manifest、10 个 planning seed 下，Two-Room/Reacher/Push-T/OGB-Cube 成功率分别为 100.0/97.0/86.0/82.2%，LeWM 为 97.4/96.0/83.6/68.0%；最大增益是 OGB-Cube 的 +14.2 点。不过这 10 个 seed 主要测规划采样，不是 10 个独立训练模型；完整组件消融只有 3 个训练 seed。论文 Table 2 与统计口径
  4. TD-JEPA 同时给出重要反例：更准确的时间排序不等于更好的接触控制代价。 在同一 TD-JEPA checkpoint 上，Push-T 使用 learned temporal cost 只有 69.0±1.9%，改回 latent L2 达 86.0±4.2%；失败主要发生在接触之后。最终 headline 因而对 Two-Room/Reacher 用 learned cost，却对 Push-T/OGB-Cube 继续用 L2。论文 Tables 7–11
  5. INTACT 的 headline 很强，但官方 evaluator 会制造近饱和假象。 一轮训练、零候选搜索的官方 PushT/Cube/Reacher/TwoRoom 成功率为 85.78/100.00/97.67/97.89%，macro 95.33%，planner-side 延迟 2.9–5.5 ms；然而在作者自己修复已知 evaluator 缺陷的 CLEAR Moderate 协议下，Reacher 从 97.67% 降到 49.56%，macro 降到 83.33%，而且论文尚未报告更严格的 Strict 结果。官方主表｜CLEAR 协议审计

JEPA 方向最新进展

1. 严格新增集中在 LeWM 下游，但解决的是两层不同接口

本轮核查了 arXiv cs.LG、cs.CV、cs.RO、cs.AI、cs.CL、eess.SP、eess.IV、cs.MM、cs.SD 的 2026-07-29 新列表，并以 JEPA、I-JEPA、V-JEPA/V-JEPA 2、A-JEPA、LeWM、joint-embedding、predictive latent 与引用链交叉发现候选。截止线后高可信新增都出现在 LeWM 控制链上：

  • TD-JEPA 解决 rollout 之后如何给候选未来排序：从无奖励示范的前后顺序挖出 directed temporal cost；
  • INTACT 解决 能否不枚举候选，直接从目标 latent 得到动作：用同一个 action-law predictor 对齐真实一步变化与部署期目标位移。

两篇都保留 LeWM 的像素输入、latent forward prediction 与 SIGReg 防坍塌骨干，因此属于 JEPA 的实际下游改造，而不是把“latent”“world model”当作 JEPA 同义词。LeWM 原论文

这也标志着 JEPA 控制研究正在从“predictor 准不准”转向三个独立接口：

  1. 预测接口：动作是否能把当前 latent 推到真实未来 latent；
  2. 代价接口：想象出的多个未来该怎样按任务进展排序；
  3. 动作接口：一个目标 latent 是否能直接被反解为可执行动作。

TD-JEPA主要改第二层，INTACT 同时改第一、第三层。它们不能互相替代：一个更好的 cost 不会自动消除搜索，一个更好的 direct actor 也不会自动成为可靠的全局验证器。

2. 严格区分实际 JEPA、仅引用与相邻 world model

TD-JEPA：实际复用并改造 JEPA。

  • 保留 LeWM 的 encoder、action-conditioned forward predictor、one-step latent MSE 与 SIGReg；
  • 用同轨迹的 step gap、跨轨迹 negatives 和 5 步 rollout consistency 训练 directed cost；
  • 下游 planner 真实消费这份 cost，或消费被 temporal supervision 重塑后的 latent L2。

INTACT：实际联合训练 JEPA 与下游动作接口。

  • forward branch 继续预测未来 latent；
  • physical-successor intent 与 deployment goal intent 共用一个概率 action operator；
  • action likelihood 的梯度会更新视觉 encoder，而不是在冻结 JEPA 特征上另训一个普通策略头；
  • actor-disabled CEM 也得到提升，说明改动不只发生在最终 action head。表示与动作接口分解实验

没有纳入主解读的候选：

  • VisualPatchWorld 与 TD-JEPA 同日在 world-model/control 列表出现，方法却是从状态—动作轨迹归纳可执行程序并用 code simulator 规划；它没有复用 JEPA encoder–predictor，不因题目含 “latent structured representations” 就算 JEPA 下游。
  • 7 月 29 日 cs.CV、cs.LG、cs.AI、eess.SP、eess.IV、cs.MM、cs.SD 新列表中，未发现另一篇同时满足“实际 I/V/A-JEPA 或 LeWM 复用 + 明确下游 + 可核对实验”的新主稿；只在 related work 提及 JEPA、实际方法仍是生成式世界模型、代码模拟器、MAE 或普通表征蒸馏的论文继续排除。
  • seq-JEPA 与 JHU-VPT(JEPA) 仍是高价值历史回补项，但今天已有两篇严格新增，不用历史论文补足数量，也不重复登记为“新进展”。seq-JEPA 官方页面｜JHU-VPT(JEPA) / MIDL 2026
  • 本轮没有发现 I-JEPA、V-JEPA/V-JEPA 2、A-JEPA 或 MJEPA 主干在截止后出现同等可信的新领域下游论文。

3. 最新信号：JEPA 的控制瓶颈已从 dynamics 转向“可查询性”

TD-JEPA 与 INTACT 都默认 LeWM 已经能做短时 latent prediction，争论焦点不再是要不要像素重建，而是“学到的世界状态怎样被控制器查询”：

  • TD-JEPA 把查询写成 energy minimization：哪个候选 rollout 的 directed cost 最低？
  • INTACT 把查询写成 conditional likelihood：这个 state–goal intent 下，专家动作分布是什么？

前者保留了模型式规划的可验证性，却仍需每步搜索；后者把搜索摊销进训练，却把可辨识范围限制在 demonstration support，并可能用对角高斯均值抹平多模态动作。论文原文也明确承认这些边界。INTACT limitations

因此，本日最稳妥的阶段性判断是：

JEPA 已能学习可 rollout 的 latent dynamics，但“可 rollout”不等于“有正确的 plan cost”，也不等于“能直接反解动作”。最新工作正在分别学习这两种查询接口，还没有证明其中任何一种可以在拓扑导航、连续到达与接触操作之间通吃。

新增下游论文解读

1. Temporal-Distance JEPA: Plan-Aware Representation Learning for Latent World Model Predictive Control

基本信息

  • 完整题目：Temporal-Distance JEPA: Plan-Aware Representation Learning for Latent World Model Predictive Control
  • 作者：Jiaxin Bai、Jiaxuan Xiong
  • 机构：Hong Kong Baptist University，KnowComp
  • 时间与出处：arXiv:2607.25337 v1，2026-07-28 06:38:16 UTC 提交；当前为 cs.CL 主分类、cs.RO 交叉分类预印本
  • 使用的 JEPA：LeWM/LeJEPA 风格的 end-to-end encoder–predictor + SIGReg
  • 下游任务：基于离线示范日志的 latent model predictive control
  • 官方代码：HKBU-KnowComp/TD-JEPA，含训练/评测代码、Hydra 配置、locked manifests、结果摘要与 MIT License；截至本次核验无 release，也未在 README 中提供 TD-JEPA checkpoint 下载

arXiv 摘要与提交记录 · 原始 PDF · 官方复现仓库

命名提示：本文的 TD-JEPA 指 Temporal-Distance JEPA。它与 7 月 24 日已经记录的 ICLR 2026 Temporal Difference JEPA（同样常缩写为 TD-JEPA）不是同一篇论文；前者学习 MPC 的时间进展代价，后者研究策略条件的 temporal-difference latent prediction 与 zero-shot RL。后文凡写 TD-JEPA，均指本日的 Temporal-Distance JEPA。

方法如何衔接 JEPA

可核对事实

TD-JEPA 不替换 LeWM 的视觉 encoder 或 action-conditioned predictor。完整损失仍包含：

  1. LeWM 的一步 future-latent MSE；
  2. SIGReg 表示防坍塌；
  3. 新增的 5 步 teacher-forced rollout consistency，使训练 horizon 对齐 planner horizon；
  4. 新增的 directed temporal-distance objective。

时间距离来自无奖励示范轨迹。对同一轨迹中的 i<j，论文把 j-i 当作前向 temporal target；对不同轨迹在同一时间索引抽到的 goal，使用 hinge 把 cost 推到 margin 之外。cost head 由 symmetric feature distance 与 asymmetric residual 组成，因此 d(z_s,z_g) 可以不同于 d(z_g,z_s)。论文方法与公式 3–9

作者主张

普通 JEPA 优化的是短时 latent prediction，而 MPC 需要对多步想象结果按“离目标还有多远”排序。示范中的前后顺序虽然不是最短路，却能提供 on-manifold progress proxy；在拓扑任务上，这种 directed cost 比偶然形成的 latent L2 更适合作为规划能量。

本研究判断

这是真正的 plan-aware JEPA 改造，但“reward-free”不等于“没有任务结构监督”：方法使用专家示范、轨迹身份、时间顺序和 task-specific plan-cost selection。它没有人工 reward，却明确利用了“哪些状态出现在同一路径、谁先谁后”的弱标签。

更重要的是，论文自己证明 directed temporal cost 不是通用 planning metric。最终系统需要先判断任务属于 topology-dominated 还是 contact-rich，再分别选择 learned cost 或 latent L2；这是一条有价值的负结论，而不是实现细节。

数据、指标、基线与关键结果

任务与协议

  • Two-Room：有障碍拓扑的视觉导航；
  • DMC Reacher：连续控制下的目标到达；
  • Push-T：平面接触推动；
  • OGBench-Cube：接触丰富方块操作；
  • 输入为 224×224 图像，ViT-Tiny 约 15M 参数，latent 维度 192，训练 10 epoch；
  • planner horizon H=5、goal offset G=25，每轮 300 个候选；Two-Room/Reacher 用 iCEM-30，Push-T 用 CEM-30，OGB-Cube 用 CEM-10；
  • primary evaluation 使用固定 50-episode manifest 与 10 个 planning seed；组件消融使用 3 个训练 seed。论文 Appendix C｜官方 README 的 locked protocol

关键机制与反例

  • 在 held-out Push-T pairs 上，LeWM latent L2 与真实 step gap 的 Spearman ρ=0.65，TD-JEPA d_ψ 为 ρ=0.95；
  • 但同一 TD-JEPA checkpoint 的 Push-T 成功率：d_ψ 69.0±1.9、blend 83.4±3.7、latent L2 86.0±4.2；
  • component ablation 的 latent-L2 planning：完整 TD-JEPA 85.3±4.2，换成 symmetric Euclidean temporal head 为 57.3±4.2，移除 cross-trajectory hinge 为 77.3±4.2，移除 rollout consistency 为 60.0±3.5；
  • Push-T 的 d_ψ 失败主要发生在 contact 后：50 个 episode 平均 14.3 个 post-contact failures，latent L2 为 6.0；
  • Reacher 若把 progressive rollout aggregation 改成 terminal-only，TD-JEPA/LeWM 由 96/94 变成 74/86，说明 planner aggregation 本身会显著改变结论。原始 PDF Tables 4、6–11

相对已有工作的创新

  1. 不额外学习 reward/value，直接从 reward-free demonstration 的 step order 挖出 directed cost；
  2. 明确区分“cost 作为部署期 planner objective”和“cost supervision 作为表示塑形信号”；
  3. 用 rollout-consistency 把训练 horizon 与 MPC horizon 对齐；
  4. 在同一 checkpoint 上系统扫描 d_ψ、L2、blend 与 contact gate，公开展示 learned cost 的适用边界；
  5. 发布训练、评测、locked manifest 与结果汇总代码，复现入口比多数新 JEPA 预印本完整。

局限、复现条件与潜在风险

  • 仍是纯仿真。 四项都来自 LeWM benchmark，没有真机、现实视觉干扰、动作延迟或安全失败统计。
  • “无奖励”仍依赖专家时序结构。 step count 只是示范路径长度上界，不是最短距离；次优、绕路或速度变化会把路径习惯写进 cost。
  • 跨轨迹 negatives 可能是假负例。 两条轨迹可能经过同一可达状态，论文用 hinge 容忍但没有解决这类语义冲突。
  • headline 使用任务特定 cost switch。 topology 任务用 learned cost，contact 任务用 L2；当前没有可自动判别或端到端学习的统一路由。
  • 统计口径偏向 planner 方差。 Table 2 的 10 个 seed 固定模型 checkpoint，只改变规划随机性；模型训练方差主要由 3-seed 消融覆盖。
  • 训练资源不透明。 论文与 README 给出 batch、epoch、模型维度和命令，但未报告 GPU 型号、训练时长、能耗；仓库也没有 TD-JEPA checkpoint release。
  • 比较仍有实现来源差异。 Push-T LeWM 使用 released checkpoint，其他环境使用作者训练的 LeWM checkpoint；RC-aux 是 concurrent baseline 的作者实现，应等待独立复核。

复现判断：中高。 代码、配置、数据名、locked manifests、seeds 和结果摘要齐全；主要缺口是 checkpoint、算力记录和独立复现。

是否值得改写成原创技术博客

值得，高优先级。 最合适的主题不是“TD-JEPA 又刷新四个分数”，而是：

一个更懂“还要走几步”的 latent 距离，为什么反而推不好积木？

这条主线可以解释 topology progress 与 contact geometry 的差异，并把 ρ=0.95 但 Push-T 69<86 的反例作为核心，而不是脚注。

2. INTACT: Isomorphic Intent-to-Action Learning for Search-Free World Models

基本信息

  • 完整题目：INTACT: Isomorphic Intent-to-Action Learning for Search-Free World Models
  • 作者：Junhan Sun、Hao Zhao、Guofeng Zhang
  • 机构：浙江大学 State Key Laboratory of CAD&CG、清华大学 Institute for AI Industry Research（AIR）、InSpatio、RoboParty Lab
  • 时间与出处：arXiv:2607.26056 v1，2026-07-28 17:59:40 UTC 提交；当前为 cs.RO 预印本
  • 使用的 JEPA：LeWM forward predictor + SIGReg，并让动作似然端到端更新视觉 encoder
  • 下游任务：PushT、OGBench Cube、DMC Reacher、TwoRoom 的 search-free 视觉目标控制
  • 代码状态：论文提供 CLEAR-LeWM v0.5.1 官方评测软件 release 与固定 commit/manifest/checkpoint 审计信息，但 arXiv 页面和正文没有给出完整 INTACT 训练代码仓入口

arXiv 摘要与提交记录 · arXiv HTML 全文 · 原始 PDF

方法如何衔接 JEPA

可核对事实

INTACT 保留 LeWM 的视觉 encoder、forward latent predictor 和 SIGReg，同时新增一个共享的概率 action operator。每条示范 transition 产生两种 intent：

  1. m_local = z_{t+1}-z_t：真实一步 successor 仍连接 encoder 梯度，用同一步专家动作监督 physical inverse call；
  2. m_goal = stopgrad(z_g)-z_t：从未来目标构造部署期 goal-intent，同样用当前示范动作监督 goal call，但目标端停止梯度。

两种 call 使用相同的 typed input grammar、共享 predictor 参数，输入当前 state、intent、state×intent interaction 与 previous action，输出对角高斯 action-block 分布。推理时取分布均值直接执行；forward predictor 继续滚动下一 latent request。可选 Guarded A 只在 direct plan 附近做 128×3=384 个候选的局部 CEM，而不再从 9,000 个随机 action sequence 起搜。方法公式与 Algorithm 2

作者主张

forward JEPA 只告诉模型“动作会把世界变成什么”，部署时却还要靠 CEM 数值反演“什么动作能把世界变成目标”。INTACT 让同一 action law 在训练时解释局部真实变化和未来目标位移，因此 latent 变成可直接查询的 intent-to-action interface。

本研究判断

这不是纯自监督世界模型。论文不使用 reward 或额外语义标签，但每一步都使用专家 action chunk 做负对数似然，goal branch 本质上含 goal-conditioned imitation；作者也明确承认这一点。论文对 GCSL/behavior cloning 边界的说明

它的真正创新不是“加一个 inverse dynamics head”，而是让 local physical intent 与 deployment goal intent 共享同一个 action operator，并让 action supervision 反向塑造 encoder。干净证据来自 shared-vs-independent actor、actor-disabled CEM 与 held-out episode audit，而不是“isomorphic”术语本身。

数据、指标、基线与关键结果

任务与协议

  • 四个官方 LeWM 视觉域：PushT、OGBench Cube、DMC Reacher、TwoRoom；
  • 模型输入 RGB 与 5-step action blocks；simulator state 只用于 probe 与 success predicate；
  • 单任务模型从头训练完整数据 1 epoch，batch 256、3 个 training seed；
  • 每个 checkpoint 用 evaluation seeds {0,1,42}，每个 seed 100 episodes；
  • 另训一个共享 ViT-Tiny/14、192 维 latent 的四任务 encoder，保留 task-specific forward/action heads，训练 5 epoch；
  • 主要基线包括 DINO-WM、LeWM、Fast-LeWM、Qantara、GC-IDM、PRISM 与 C-JEPA。实验协议

最有解释力的 matched evidence

  • PushT actor-disabled CEM：LeWM 42.22±9.50% → 加 physical inverse 57.67±2.52% → 加 matched waypoint intent 61.44±2.04% → 完整 waypoint INTACT 69.44±1.64%；最后一行同时改变 SIGReg，因此不能当作单一 intent 消融；

论文明确说明 INTACT 尚未完成 Strict 协议，因此不能把 official/Mild near-ceiling score 写成精密物理控制已解决。CLEAR Moderate/Strict 定义与结果

相对已有工作的创新

  1. 将 local physical successor 与 deployment goal displacement 组织成共享 action-law operator 的两种条件调用；
  2. action likelihood 端到端更新 JEPA encoder，而不是冻结 LeWM 后另训 policy/prior；
  3. 在 Direct、actor-disabled CEM、actor-on CEM 和 local verification 间完整分解表示、readout 与搜索贡献；
  4. 同时报告 task-specific 与 shared four-task encoder，检验跨异构动作域共享视觉表示；
  5. 发布独立 evaluator 审计并主动揭示官方协议的自动成功、坐标和碰撞检查问题；
  6. 用 episode-disjoint、actor-sharing、goal shuffle/gauge 等大量机制实验，减少“只是记住示范目标”或“只是额外 head 容量”的解释空间。

局限、复现条件与潜在风险

  • 监督边界。 无 reward 不等于无监督；动作标签直接进入 physical inverse 与 goal-conditioned likelihood，方法更接近 JEPA + goal-conditioned imitation。
  • 只在 demonstrated support 可辨识。 单条专家动作不能告诉模型其它动作是否也有效；障碍绕行、接触切换和多模态示范可能让 goal displacement 变得歧义。
  • 对角高斯均值会抹平多模态。 在路口或接触切换处，均值可能落在多个合法动作之间；启用搜索可验证，却不再是严格 zero-search。
  • 官方 evaluator 明显偏乐观。 CLEAR Moderate 下 Reacher 成功率减半，Strict 尚未完成；历史 near-ceiling 结果不能直接外推。
  • 仍是四个仿真环境。 没有真机、现实视觉、时延、动作噪声、碰撞、安全恢复或 OOD 拒绝实验。
  • 训练方差有限。 完整矩阵只有 3 个 training seed，论文也称其只是 coarse estimate。
  • autoregressive latent drift。 Direct 第一步后会在 predictor 生成的 latent 上继续条件化，仍存在与真实 encoder state 的分布偏移。
  • 复现入口不完整。 CLEAR evaluator、固定 commit、manifest 与公开 checkpoint 审计信息可核对，但论文没有给 INTACT 训练代码仓；也未报告 GPU 型号、训练时间或能耗。
  • 论文复杂度高。 28 页包含大量 gauge、CKA、kNN、t-SNE 与历史实验；这些诊断能支持机制，但不是控制正确性的 certificate，作者在限制章节也明确承认。

复现判断：中。 评测协议和结果审计很完整，但核心训练实现、算力与真机条件缺失。

是否值得改写成原创技术博客

值得，高优先级。 推荐主题：

世界模型为什么会预测却不会行动？INTACT 把 CEM 搜索摊销进了 latent intent

文章必须把三个边界放在主线：它使用专家动作监督；Direct 的优势主要来自学出的 action conditional，不是 forward model 单独变强；Reacher official→CLEAR Moderate 的大幅回落说明 evaluator 定义会改变“search-free 已解决”的结论。

两篇共同证明了一件事：

JEPA 的 forward prediction loss 不会自动产生一个好用的控制查询接口。

但两篇没有证明同一件事：

  • TD-JEPA 证明 temporal supervision 可以改善表示或规划 cost，但 planner 仍负责数值搜索；
  • INTACT 证明 action-supervised intent interface 可以摊销搜索，但不是仅靠无标签 JEPA 自发出现；
  • TD-JEPA 的进度排序会丢失接触几何，INTACT 的 direct Gaussian 会丢失动作多模态；二者分别压缩了控制问题的不同信息。

从研究设计看，最值得做的下一步不是宣布其中一条路线胜出，而是在同一 LeWM checkpoint、同一 corrected evaluator 下比较：

  1. 原始 L2 + CEM；
  2. TD-JEPA learned cost + CEM；
  3. INTACT Direct；
  4. INTACT Direct 初始化 + TD-JEPA cost 验证。

这才可能回答“学 cost”和“学 actor”是否互补。

值得继续追的问题

  1. TD-JEPA 的 step count 能否换成更稳健的 progress label？ 可比较 shortest-path proxy、dynamic time warping、successor features、quasimetric Bellman consistency 与 uncertainty-aware labels。
  2. cross-trajectory negatives 的假负例有多严重？ 应用已知可达状态、轨迹交叉点或 learned connectivity graph 审计被错误推远的 goal pairs。
  3. 为什么 temporal cost 在 contact 后失败？ 需要把 cost 对位置、朝向、接触法向、摩擦状态与 action sensitivity 的 Jacobian 分解，而不只统计 failure phase。
  4. 能否自动选择 d_ψ 与 L2？ 目前由研究者预先标注 topology/contact regime；下一步应学习 calibrated gate，并避免用 test success 反向选 cost。
  5. TD-JEPA 的提升是否跨 training seed 稳定？ Table 2 应补独立训练 checkpoint 的均值/方差，而不只固定 checkpoint 后重复 planner sampling。
  6. INTACT 是否只是更强的 goal-conditioned behavior cloning？ 需要与同 encoder、同 action head、同 goal sampling、但移除 forward JEPA 或冻结 encoder 的完整 factorial 比较。
  7. INTACT 的动作分布如何表达多模态？ 可比较 mixture density、flow/diffusion actor、uncertainty-triggered verifier，并观察 mode coverage 与安全失败。
  8. corrected Strict 协议下还剩多少优势？ CLEAR Moderate 已让 Reacher 减半；PushT/Cube/Reacher/TwoRoom 的 Strict 结果和失败日志是下一轮最高优先级版本追踪项。
  9. 两篇能否在同一 corrected benchmark 直接对比？ TD-JEPA 使用 50-episode locked manifests，INTACT 使用 100-episode official/CLEAR；当前跨论文数字不能直接排名。
  10. 真实机器人上 search-free 的价值是否仍成立？ 必须把 encoder、相机、通信、控制周期、动作执行延迟纳入 end-to-end latency，并报告碰撞与恢复。
  11. TD cost 与 INTACT actor 能否组合？ 用 actor 产生结构化 proposal、用 learned directed cost 做少量验证，可能同时减少 9,000-sequence 搜索和纯 Direct 的多模态风险。
  12. 历史回补队列继续保留。 若下轮无严格新增，优先深读 seq-JEPA 的 invariant/equivariant 分解与 JHU-VPT(JEPA) 的多中心手术视频证据，不用弱新稿凑数。

博客价值判断

首选：把两篇改写成一篇“控制查询接口”原创文章

优先级：很高。 推荐标题：

JEPA 会预测，然后呢？学一个规划代价，还是直接反解动作

建议结构：

  1. LeWM 为什么从 forward prediction 到控制还缺一跳；
  2. TD-JEPA：把示范时间顺序变成 directed energy；
  3. INTACT：把 state–goal latent 位移变成 action law；
  4. 两个关键反例：ρ=0.95 仍推不好积木；97.67% 在修正 evaluator 后变 49.56%；
  5. 组合路线：actor proposal + cost verification。

这会明显区别于“JEPA追踪”日报：原创文章围绕一个技术矛盾组织材料，不按论文逐篇复述。

TD-JEPA 单篇也有高博客价值

适合写“距离函数并不等于规划代价”。其最大优势是论文主动展示 learned cost 的失败区间，并公开代码；即使不写 INTACT，也能形成有独立观点的文章。

INTACT 单篇建议等待两个复现信号

  1. 完整训练代码或 checkpoint bundle 的明确入口；
  2. CLEAR Strict 四任务结果。

当前可以写方法审计，但不宜用“300× 加速且控制无损”作标题，因为 2.9–5.5 ms 只是 planner-side latency，且 corrected protocol 已改变 Reacher 结论。
