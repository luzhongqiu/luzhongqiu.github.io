今日结论

今天新增三篇高价值下游论文，证据强度和关注点互补：

  1. NeuroVFM / Vol-JEPA 是目前最接近临床工作流验证的 JEPA 下游工作。 它在 524 万个真实 MRI/CT 体数据上预训练，正式发表于 Nature Medicine，不仅有同一健康系统数据上的 NeuroMAE 等对照，还完成了 1,155 例连续病例的一周静默前瞻分诊。不过，这仍不是临床部署：模型漏掉了 155 个危急病例中的 21 个，且原始训练数据无法公开。期刊原文
  2. MoP-JEPA 把问题从“潜空间是否好”推进到“一个 predictor 能否表示多个未来”。 在随机分支环境里，单一 JEPA 回归器会预测多个后继的均值；硬分配多头 predictor 可以把未来作为有限候选集交给规划器。其 verified-route 指标在三个 OGBench 迷宫上都优于同协议 predictor 基线，但最难任务存在明显种子双峰，且在 DINO-WM 像素闭环实验上没有统计显著的执行提升。arXiv 原文
  3. P-JEPA 表明 JEPA 可以作为“长时序适配层”叠加在 V-JEPA 2.1 等短片段特征之上。 它把最长 30 多分钟的程序视频压成逐帧特征流，再做 take-level latent prediction，在在线动作理解和时间动作分割上取得明显提升。但最佳管线依赖人工 segment 边界，部分 V-JEPA 2.1 特征还使用动作标签训练 pooler，因此不能简单宣传为端到端、完全无监督的长视频理解。arXiv 原文

综合博客价值排序：NeuroVFM（很高） > MoP-JEPA（高） > P-JEPA（中高）。今天最值得写的主线不是“JEPA 又进入三个领域”，而是：

JEPA 的下游竞争已经从统一的 masked latent prediction，分化到三个不同工程层级——用领域结构决定遮什么、用多头预测器表示多少个未来、用更高层的 JEPA 重新组织多长的时间上下文。

JEPA 方向最新进展

1. 从二维图像先验走向领域结构化 masking

昨日的 US-JEPA 用超声有效区域约束 masking；今天的 NeuroVFM 更进一步，把 I-JEPA/V-JEPA 改为 3D Vol-JEPA，只从头部 foreground 中采样 context 和 target，并针对 MRI/CT 设置不同可见比例。这说明 JEPA 在专业领域的关键变量已不只是 backbone，而是 mask 是否对应领域中可预测、又足以迫使模型学习语义的结构。NeuroVFM 方法

2. 从确定性 latent regression 走向多未来接口

GeoWorld 和 Temporal Straightening 关注潜空间几何是否适合 rollout；MoP-JEPA 则指出更前置的瓶颈：如果环境本身是一对多，即便潜空间几何良好，单一回归输出仍可能落在所有合法未来之间。其贡献不是发明多选择学习，而是把 hard-assigned heads 变成 JEPA planner 可直接消费的 successor-set interface，并用 transition precision 与 verified-route 防止“多猜几个就覆盖更多”的虚假提升。MoP-JEPA 方法与评测

3. JEPA 开始成为 JEPA 之上的层次化适配器

P-JEPA 并不重新处理原始 RGB，而是在 V-JEPA 2.1、TSM 或 I3D 的逐帧特征流上，再训练一个带 EMA teacher 的 take-level JEPA。它把短时视觉编码和长时程序结构拆成两个层级：底层回答“画面里发生什么”，上层回答“这一步在整个流程中处于什么位置”。这是一条现实的长视频扩展路线，但也把输入特征质量、segment 边界和监督 pooler 变成新的依赖。P-JEPA 方法

4. A-JEPA / 音频方向今日没有高可信新增

本轮检索覆盖了 A-JEPA/Audio-JEPA、I-JEPA、V-JEPA/V-JEPA 2/2.1、医学体数据、规划、程序视频、粒子物理、遥感和生理信号等关键词。没有发现一篇在已有记录之外、又能用一手全文核验为“实际采用 A-JEPA 并完成具体新增下游任务”的高可信论文，因此今天不以低质量结果补位。

新增下游论文解读

1. NeuroVFM：在真实健康系统数据上把 Vol-JEPA 接到诊断、报告与分诊

完整题目：Health system learning enables generalist neuroimaging models
作者：Akhil Kondepudi、Akshay Rao、Chenhui Zhao、Yiwei Lyu、Samir Harake、Soumyanil Banerjee、Jacob Ogle、Rushikesh Joshi、Anna-Katharina Meissner、Xinhai Hou、Cheng Jiang、Asadur Chowdury、Ashok Srinivasan、Brian Athey、Vikas Gulani、Aditya Pandey、Honglak Lee、Todd Hollon。
机构：以 University of Michigan 的 Machine Learning in Neurosurgery Lab、Computational Medicine and Bioinformatics、Computer Science and Engineering、Neurosurgery、Radiology 为主，另有 University of Cologne Neurosurgery。
时间与出处：2026-07-10，Nature Medicine，开放获取、已同行评审。
代码与权重：官方 GitHub 提供训练和评测代码（MIT）；模型权重使用 CC-BY-NC-SA-4.0，部分需机构邮箱审批。原始临床影像受隐私与 IRB 限制，不能公开。

它实际使用了哪种 JEPA？

Vol-JEPA 明确扩展 I-JEPA 与 V-JEPA 到三维临床影像：

  • 将 MRI/CT volume 切成 4 × 16 × 16 的非重叠 3D patches；
  • 在线 3D ViT 只编码小块可见 context，predictor 结合 context latent 与 target 位置编码预测被遮挡区域；
  • EMA teacher 编码完整 volume，并用 stop-gradient 的 target latent 监督 smooth L1；
  • context/target 仅从头部 foreground mask 中采样，MRI/CT 最优 context 比例分别为 25%/20%，另随机丢弃 20% context patches；
  • 推理时丢弃 teacher 和 predictor，用完整 volume 的 encoder tokens 服务所有下游任务。

这不是仅引用 JEPA，也不是把现成 I-JEPA 特征接分类器，而是对 数据形态、masking policy、可变长 3D token 计算与跨模态 CT/MRI 训练 的系统改造。Vol-JEPA 训练细节

下游任务、数据集、指标与基线（事实）

  • 预训练集 UM-NeuroImages：Michigan Medicine 20 多年常规临床数据，566,915 个 MRI/CT studies、5,239,579 个 3D series/volumes。训练和测试按时间切分，2023-06-01 前为训练，2023-06-01 至 2024-05-31 为测试。
  • 诊断：82 个 CT 与 74 个 MRI 多标签诊断，共 156 个任务；时间外推测试包含 21,054 个 CT studies 和 29,239 个 MRI studies。冻结 encoder，统一训练 study-level attentive probe；主指标为 macro AUROC，并报告 balanced accuracy、sensitivity、specificity 与 bootstrap 95% CI。
  • 外部迁移：覆盖 ADNI→AIBL/OASIS-1 阿尔茨海默病、CQ500、RSNA-ICH、BraTS21 等公开任务；另评测跨 MRI sequence、跨 CT/MRI 的解剖与病灶表征。
  • 报告生成：冻结 NeuroVFM encoder，通过 Perceiver/MLP 接 Qwen3-14B，按 LLaVA-1.5 风格微调生成结构化影像 findings；300 个专家核验 studies 上与 GPT-5、Claude Sonnet 4.5、MedGemma 比较。
  • 静默前瞻分诊：2026-01-18 至 01-25 连续一周的 1,155 个 studies（601 MRI、544 CT），其中 155 例至少有一个 critical finding。模型不影响临床决策。
  • 主要表征基线：同健康系统数据上的 HLIP、PRIMA、compute-matched NeuroMAE，以及互联网规模 DINOv3、BiomedCLIP。所有 encoder 冻结并使用统一 probe；其中 NeuroMAE 使用同一预训练数据、3D ViT 与优化设置，是最接近“只改变自监督目标”的对照。

事实、作者主张与我的推断

  • 事实：这是本轮证据链最完整的 JEPA 下游论文。它有同健康系统自监督基线、时间切分、外部公开基准、专家盲评、静默前瞻和公开代码；JEPA 并非只出现在模型命名中。
  • 作者主张：直接从健康系统未精挑数据中学习，比互联网预训练或报告监督更能获得通用神经影像表征；Vol-JEPA 能同时保留解剖空间与疾病语义。
  • 我的推断：论文最强的因果证据是同语料的 NeuroMAE/HLIP 对照，而不是“击败 GPT-5”。GPT-5/Claude 接收的是受 API 限制的 2D slices（GPT-5 最多约 15 个 sequences/360 slices），NeuroVFM 是为完整 3D study 定制并见过该健康系统的大规模私有数据；这更能证明 领域原生 3D perception module 的必要性，不能单独证明 JEPA 目标本身优于所有通用多模态模型。

局限、复现条件与风险

  • 训练数据虽然来自 Michigan Medicine 多中心，但仍属于单一健康系统；作者明确要求未来做跨健康系统前瞻研究。外部公开基准缓解了这一点，但不能替代真实跨院工作流验证。
  • 时间切分不是严格的 patient-disjoint split：测试患者中约 34.7%（MRI）和 31.8%（CT）曾在训练时间窗出现。作者删除重叠患者后模型排序大致不变，但这仍应与真正的新院、新患者验证分开理解。
  • 诊断标签由 GPT-4.1-mini 从报告中抽取，只有分层子集经专家核验；这不影响无标签预训练，却会影响 probe 训练和诊断评测的标签噪声。
  • 前瞻研究仅一周、静默运行，没有测量病人结局、读片时间或医生行为变化，也不是随机临床试验。21/155 个 critical misses 说明它不能作为自主筛查工具。
  • 报告/分诊结果来自完整管线：Vol-JEPA encoder + Perceiver/MLP + Qwen3-14B + 固定 reasoning model，提升不能全部归因于 Vol-JEPA。
  • 复现软件与算力信息较完整：典型节点为 8×L40S 48GB，完整预训练少于 1,000 aggregate GPU-hours，batch 768、约 510k steps；单 volume ViT-B 推理峰值约 1.10GB、跨 encoder size 吞吐约 84 volumes/s。
  • 代码已公开，但原始 9TB 级临床数据不可公开、权重有非商业与访问限制，因此“复现实验代码”与“复现训练语料”必须区分。
  • 医疗风险：模型未获 FDA 批准，官方仓库明确标注 research use only；任何博客都必须避免将 silent prospective feasibility 描述为已临床部署。

博客价值

很高，建议优先成文。 可写成：“当 JEPA 进入 524 万个 3D 脑扫描：真正击败通用模型的是领域数据、体素原生架构，还是 latent prediction？”文章应以 matched-data NeuroMAE 对照和 21 个危急漏诊为两条边界，避免“AI 已替代神经放射科”的叙事。

2. MoP-JEPA：让 JEPA 在随机环境里显式枚举多个未来

完整题目：MoP-JEPA: Hard-Assigned Predictor Mixtures for Stochastic JEPA World Models
作者：Zhi Song、Ximing Xing、Zhenchao Tang、Hanbo Huang、Weilong Yan、Tianxu Lv、Minghao Yang、Zhongzheng Niu、Bing He、Lusheng Wang、Jianhua Yao。
机构：City University of Hong Kong、Tencent。
时间与出处：arXiv v2，2026-07-11；当前为预印本。
代码状态：截至本次检索，arXiv 页面与公开搜索未给出作者官方代码仓。

它如何衔接 JEPA？

论文明确引用 I-JEPA、V-JEPA、V-JEPA 2 与 DINO-WM，并保持 online encoder、EMA target encoder、stop-gradient 与 action-conditioned latent prediction 不变，只替换 predictor：

  • 标准 JEPA 对每个 (state, action) 输出一个 next latent；平方损失的最优解是多个未来的条件均值，cosine loss 则是归一化均值方向。
  • MoP-JEPA 让 K 个 predictor heads 同时输出候选；每个 target 只更新距离最近的 winner head（best-of-K / WTA hard assignment）。
  • context-only router 只看当前状态与动作，不看真实未来；用 winner head index 做交叉熵监督，并加入 load-balancing。
  • 推理时一次前向返回带 router 权重的有限 successor set，BFS/graph search 或 MPC 可直接枚举这些后继，而不是从单高斯或 decoder 反复采样。

它改变的是 JEPA 的 预测接口与训练分配机制，而非只在相关工作引用 JEPA。模型结构与目标

下游任务、数据集、指标与基线（事实）

  • 主任务：官方 OGBench 离线 goal-conditioned planning，包括 pointmaze-medium-stitch、pointmaze-large-stitch、pointmaze-teleport-navigate 与 29-D antmaze-teleport；20% unique transitions 留出。
  • 额外机制验证：ETH/UCY 行人轨迹、SVHN 下半图补全、pixel observations 与 DINO-WM predictor override。
  • 核心指标：planAll（在预测图上能否找到路线）、official-goal success、transition precision、realroute（模型先盲建图，再用真实转移核验整条路线是否存在）与 closed-loop execution success。
  • 基线：dense JEPA、加权融合 M3-JEPA、单高斯 Var-JEPA、Mixture Density Network（MDN）、input-agnostic codebook；同协议 predictor 比较共享 encoder、数据和 planner。外部 OGBench GCRL 数字只作背景，不是同协议比较。
  • 主表使用 K=8、30k steps、5 seeds；coverage/execution 部分为 3 seeds。

  • realroute 相对 MDN 在三图的倍率为 1.8×/4.9×/2.4×；但 large-stitch 五种子置信区间包含 0，作者将其标为不确定，而不是显著胜出。
  • 闭环执行并非全面最好：medium-stitch 上 MDN 0.87、MoP-JEPA 0.67；large-stitch 上 MoP-JEPA 0.33、MDN 0.27、dense 0.13。外部 QRL 为 0.84，但训练目标与协议不同，论文明确不宣称击败这类 GCRL 方法。

事实、作者主张与我的推断

  • 事实：在共享 encoder/data/planner 的控制实验里，单输出 predictor 在随机分支处会落到无效中间点；hard-assigned heads 能恢复多个 successor，并在三个迷宫的 verified-route 均值上领先。
  • 作者主张：多模态动力学决定 JEPA world model 是否可规划；有限候选集比单输出、加权 MoE 或单高斯更适合搜索。
  • 我的推断：这篇最重要的不是 0.85 planAll，而是它证明 覆盖率不是多未来模型的充分指标。input-agnostic codebook 可获得 1.0 raw coverage，却没有上下文依赖；verified-route/precision 才能暴露“预测了不存在的边”。这套评测思想比具体 hard-EM 实现更可能迁移到 V-JEPA 2、diffusion world model 与机器人规划。

局限、复现条件与风险

  • 主结果仍来自低维迷宫；29-D antmaze 与像素观察上的增益更弱。
  • hardest maze 的 WTA 优化高度依赖初始化，成功 basin 命中率只有 2–8/10；虽然作者主表报告未挑选种子的均值，但 restart-selection 规则只在当前任务族验证。
  • 四分支节点里，完整找回四个模式的比例只有 37%；低于 10% 概率的 rare successor 容易丢失。
  • 在官方 DINO-WM 像素闭环随机 teleport 变体中，MoP 对 dense 的 MPC execution 提升没有统计显著性，说明 verified latent graph 的改善尚未转化为大型视觉闭环收益。
  • predictor-family 基线为作者同协议重实现；MDN 有网格搜索，Var-JEPA/M3-JEPA 为 matched capacity/shared hyperparameters，但没有外部复现与代码。
  • 调参后的 MDN 在 large-stitch 可达 realroute=0.191，高于 MoP-JEPA 主协议均值 0.139；这进一步说明该任务不能写成 MoP 全面胜出。
  • 论文未完整给出 predictor/encoder 层数、hidden size、优化器、学习率、batch、硬件和训练耗时等关键复现信息；无代码使这些缺口目前无法补齐。
  • 该方法枚举 aleatoric futures，却不能提前知道实际会发生哪一条；如果 planner 把候选误当成可控分支，会产生错误决策。

博客价值

高。 最适合与 GeoWorld、Temporal Straightening 合写：“JEPA 规划的三个瓶颈：潜空间几何、时间曲率与多未来平均化”。单篇标题可用：“一个未来不够：为什么 JEPA 的 predictor 会把岔路预测到墙里”。

3. P-JEPA：在 V-JEPA 2.1 特征上学习 30 分钟级程序结构

完整题目：P-JEPA: Procedural Video Representation Learning via Joint Embedding Predictive Architecture
作者：Felix Tristram、Stefano Gasperini、Benjamin Killeen、Marcel Walch、Christian Benz、Nassir Navab、Ghazal Ghazaei。
机构：Technical University of Munich、Munich Center for Machine Learning、Carl Zeiss AG。
时间与出处：arXiv v1，2026-06-22；当前为预印本。
代码状态：截至本次检索，arXiv 页面未给出作者官方代码仓。

它如何衔接 JEPA？

P-JEPA 是双层结构：

  1. 用冻结的 V-JEPA 2.1、TSM 或 I3D 将原始长视频变成 4 fps 的 frame-aligned feature stream；V-JEPA 2.1 特征采用 mean-pool 或带监督的 action-pool。
  2. 在完整 take 的特征流上训练第二个 JEPA：4 层 student encoder、2 层 predictor、EMA teacher、60%/80% 随机 latent masking；student 看 context tokens，predictor 预测被遮挡位置的 teacher latents。
  3. 采用 clip-causal attention：同一人工 segment 内双向注意力，可看历史 segments，不可看未来；2D RoPE 分别编码 segment index 与 segment 内 frame index。
  4. 下游丢弃 teacher/predictor，冻结 P-JEPA encoder，训练线性、流式或 temporal action segmentation probe。

它实际复用 JEPA 目标，并把 V-JEPA 2.1 从短 clip encoder 变成长程序模型的输入，不是只引用 JEPA。方法原文

下游任务、数据集、指标与基线（事实）

  • EgoExo4D fine-grained action classification：14,326/4,517 train/validation clips，648/180 takes，278 类；最长 take 34.5 分钟；指标 Top-1 accuracy。
  • EgoProceL：914 个视频、117.9 小时、19,943 segments、115 个 foreground steps + background；731/183 train/test，最长 36.6 分钟；评测在线 streaming 与 15%/33%/50%/100% 标签量。
  • Assembly101 单固定视角：393/120 train/validation takes、62.5 小时、6,409 coarse action segments，最长 30.8 分钟。
  • 时间分割指标：frame accuracy、normalized Edit、segmental F1@10/25/50。
  • 表征输入基线：raw V-JEPA 2.1 mean/action-pooled features、TSM、I3D；下游模型包括 linear probe、LTContext、FACT、作者改造的 LT-Causal，并与 EgoExo4D VideoLLM 方法比较。

关键结果（作者报告）

Assembly101：

输入与 probe P-JEPA Acc Edit F1@50
V-JEPA 2.1 action-pool + linear 否/是 34.0 / 40.0 18.5 / 27.8 10.2 / 16.9
TSM + LTContext 否/是 40.2 / 42.9 32.2 / 35.9 22.4 / 26.4

EgoProceL streaming：

下游模型 P-JEPA foreground Acc Edit F1@50
FACT 否/是 19.2 / 39.1 18.1 / 28.8 10.9 / 24.1
LT-Causal 否/是 55.3 / 58.8 40.2 / 48.9 25.7 / 34.4
  • sparse-label 条件下，33% 标签的 P-JEPA+FACT 已接近或超过 50% 标签的 I3D+FACT：Acc 66.1 vs 67.5、Edit 65.2 vs 64.6、F1@50 52.2 vs 48.1。
  • 标签量达到 100% 时，FACT+P-JEPA 并非全面更好：foreground Acc 81.2 vs 81.8、Edit 81.6 vs 83.7，只有最严格的 F1@50 为 69.8 vs 68.1。P-JEPA 的优势主要集中在低标签与在线条件。
  • EgoExo4D 官方 fine-grained action classification：P-JEPA + streaming probe Top-1 为 56.85%，ProVideLLM 为 44.36%；完整管线约 1.2B 参数，在 RTX 3090 上作者测得约 20 fps。
  • clip-causal attention 消融优于 token-causal 与 bidirectional：Assembly101 TSM linear Acc 40.1 vs 35.6/37.6，支持“segment 内共享、segment 间因果”的设计。

事实、作者主张与我的推断

  • 事实：P-JEPA 在三种输入 feature families、三个程序视频数据集和多种 probes 上都提高了任务指标；在线 streaming 和 sparse-label 结果尤其明显。
  • 作者主张：take-level latent prediction 在没有 action label、narration、transcript 或 procedure graph 的情况下，能让特征编码流程位置和长程依赖。
  • 我的推断：更准确的说法应是“P-JEPA 预训练损失不使用 action class”，而不是“整个系统无监督”。模型需要 segment boundaries；action-pooled V-JEPA 2.1 feature 明确使用 action labels 训练 pooler，TSM features 也经过数据集监督微调。最强 EgoExo4D 结果因此证明的是 长程 JEPA adapter 对监督对齐的短程特征仍有增益，不是从原始视频无标签端到端学出全部程序知识。

局限、复现条件与风险

  • clip-causal mask 依赖人工 segment boundaries，实时视频通常没有这些边界；作者建议未来改 fixed-window block-causal，但尚未实验。
  • mean-pooled V-JEPA 2.1 是较弱输入；更强 action-pool 需要标签，这使不同 input rows 的监督预算并不统一。
  • P-JEPA checkpoint 每 20 epochs 用 probe 评估并保存最佳点；如果 probe validation 参与选模，表示学习与下游标签并非完全隔离，复现时应严格说明数据使用。
  • Assembly101 只使用一个固定 RGB view，不能外推到完整多视角设置。
  • 训练 1,000 epochs，但 token 总量不大；作者报告单个 P-JEPA 在 1×H200 上训练 8–12 小时，action-pool 用 1×H100，软件为 Python 3.11/3.12、PyTorch 2.6、CUDA 12.6。
  • 当前无官方代码；实时 20 fps 是作者在 RTX 3090 上拼接组件的 inference-only dummy setup，不含视频解码和完整部署开销。

博客价值

中高。 它适合写“V-JEPA 看几秒，P-JEPA 看半小时：JEPA 如何分层处理长视频”。文章必须把 action-pool 与 segment boundary 的监督依赖摆在结果旁边，否则容易把“latent prediction 阶段无标签”误写成“完整管线完全无监督”。

横向比较

论文 JEPA 改造层级 具体下游 最强证据 最主要混杂/风险 当前证据等级
NeuroVFM 3D tokenization、foreground masking、Vol-JEPA 大规模训练 156 项诊断、外部迁移、报告生成、静默分诊 同健康系统自监督对照、时间切分、外部基准、300 例专家评测、1,155 例静默前瞻 单健康系统；完整报告管线变量多；危急病例仍有 21/155 漏诊；原始数据不可公开 高：Nature Medicine 正式论文
MoP-JEPA 将单 predictor 改为 hard-assigned head set + router 随机环境 goal-conditioned planning 同 encoder/data/planner 的 predictor 隔离实验；verified-route 与精度控制 低维迷宫为主、种子双峰、rare mode 丢失、视觉闭环无显著执行增益 中：新预印本，机制证据强
P-JEPA 在短视频/动作特征之上再加 take-level JEPA 长程序动作分类、在线理解、时间分割 三数据集、多 feature family、多 probe 一致提升 依赖 segment boundary；最佳输入含监督；无代码；非端到端 RGB 中：新预印本，应用证据较广

三者共同说明：

  1. “用了 JEPA”已经不够区分论文。 NeuroVFM 的核心是领域结构 masking 与数据规模，MoP-JEPA 的核心是预测分布接口，P-JEPA 的核心是时间层次。
  2. 最可信的归因来自 matched protocol。 NeuroVFM 对 NeuroMAE、MoP-JEPA 对 dense/MDN predictor 的比较相对干净；P-JEPA 的输入监督预算差异更大，应更谨慎。
  3. 下游成功并不等于部署成功。 NeuroVFM 是静默前瞻而非临床干预；MoP 的 verified graph 不一定提高闭环执行；P-JEPA 的实时速度没有包含完整视频系统。
  4. target/predictor interface 正在成为 JEPA 的真正设计空间。 昨日 BA-Future-JEPA 选择任务感知 target，今天 MoP-JEPA 选择多未来输出，NeuroVFM/P-JEPA 选择不同结构粒度的 context-target。

值得继续追的问题

  1. NeuroVFM 的增益到底有多少来自 Vol-JEPA？ 下一步最值得复核官方代码与 supplementary：NeuroMAE 是否完全同 3D ViT、同训练步数与同数据量；把公开权重放到更多外院数据时，校准、亚群公平性和 critical sensitivity 是否保持。
  2. MoP-JEPA 能否在 V-JEPA 2-AC 真实机器人数据上提高闭环成功？ 需要真正不可控、多分支的视觉动力学，而不是人工 teleport；还要比较 diffusion/RSSM 的多样性、transition precision 与算力。
  3. P-JEPA 能否摆脱人工 segment boundaries？ fixed-window/block-causal、自动边界检测和 streaming token compression 是否仍能维持增益，是它能否进入在线助手的关键。
  4. JEPA 的“多未来”与“潜空间几何”是否可以合并？ MoP-JEPA 枚举分支，GeoWorld 用双曲空间组织层级，Temporal Straightening 降低局部曲率；组合后可能既表示分叉，又控制长程误差。
  5. A-JEPA 的下游证据为何相对少？ 后续应继续追音频事件检测、语音、声学场景和音视频跨模态任务，但坚持只纳入实际训练/评估 JEPA 的论文。

博客价值判断

首选：NeuroVFM 单篇深度解读

推荐标题：

524 万个脑部 MRI/CT 之后，Vol-JEPA 真的比像素重建更懂神经影像吗？

成文时建议围绕三组对照展开：Vol-JEPA vs NeuroMAE、NeuroVFM vs report-supervised HLIP、领域 3D 模型 vs 受输入限制的通用 MLLM。结尾必须讨论 21 个危急漏诊、数据不可公开和单健康系统边界。

次选：JEPA 规划专题

推荐把 MoP-JEPA 与昨日 GeoWorld、候选 Temporal Straightening 合并：

JEPA 世界模型为什么还不会规划：几何不直、未来不止一个、误差会累积

这比单纯复述一个 leaderboard 更有原创观点，也能清楚区分 representation、transition distribution 与 planner 三层责任。

P-JEPA 适合做长视频路线案例

它适合作为“层次化 JEPA”章节，与 V-JEPA 2.1 的 dense short-clip features 对照。若单独成文，应把“预训练目标无标签”和“管线依赖监督边界/池化”分开。
