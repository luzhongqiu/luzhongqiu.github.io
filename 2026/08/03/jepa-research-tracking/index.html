今日结论

  1. 今日无截止后新投稿，但有 3 篇高可信追踪新增。 Auto-JEPA 把冻结 V-JEPA 2 接到未来轨迹 latent；MoRAE 从头训练 Motion-JEPA，再把其特征压成适合 flow matching 的生成 latent；Physics-Aligned SSL 则把 I-JEPA 作为五种自监督方法之一，在电镜分类和晶体取向回归上做同骨干、同数据的直接评估。三篇都不是 related-work 引用。
  2. Auto-JEPA 的亮点是把 JEPA latent 变成可执行轨迹的检索键。 它用单前视相机在 NAVSIM v1 得到 91.3 PDMS，高于表中 AutoVLA 89.1、RecogDrive 89.6、DriveVLA-W0 90.2 与 Curious-VLA 90.3；NAVSIM v2 在更新后的官方 evaluator 下为 89.1 EPDMS。主结果
  3. 但 Auto-JEPA 的 91.3 不是“纯 JEPA predictor”的独立收益。 只靠 intent 检索与 gate 已有 87.6 PDMS，加入 CLOVER 初始化的 scene scorer 后才到 91.3；论文没有 matched direct-regression、no-JEPA target space 或替代视频 encoder 对照。最强结论是“完整检索—评分系统有效”，不是“JEPA 单独贡献 91.3”。组件消融 Table 3
  4. MoRAE 提供了一个重要反例：语义好的 JEPA 表示不等于可直接生成。 原始 768 维 Motion-JEPA 特征的 flow condition number 为 1.3×10^4；压到 32 维并做 motion-coupled decoding 后降到 27。直接在宽特征上生成的 gFID 为 0.358，MoRAE 为 0.089。几何诊断｜消融
  5. MoRAE 的下游结果强，但复现入口尚未兑现。 HumanML3D 上 MoRAE 的 FID/R@1 为 0.089/0.512，优于 MARDM 的 0.114/0.500；KIT-ML 为 0.169/0.410，优于 0.242/0.387。不过论文只报告主表的均值±误差，未说明误差定义、统计重复次数或独立训练 seed；官方仓库 当前只有 README，代码、权重和用法仍待发布。
  6. Physics-Aligned SSL 是今天最有价值的负/弱结果。 物理对齐增强让 I-JEPA 的 NFFA 全量微调准确率 72.27±1.15→73.41±0.75，但 linear probe 41.09→41.01 基本不变；4D-STEM 取向误差 11.49°→10.72°，仍不如 scratch 10.01°，更远落后于 MAE 1.75°。这支持“增强设计能改善 I-JEPA 的部分域内表现”，不支持“I-JEPA 是该科学成像任务的最佳 SSL”。Tables 2–4
  7. 今天的共同判断：JEPA latent 进入下游后，真正的瓶颈是接口几何。 Auto-JEPA 需要把 latent 变成轨迹检索与安全评分接口；MoRAE 需要把 latent 变成稳定的高斯传输空间；科学成像则要求增强所编码的不变性符合测量物理。仅证明“预测 loss 收敛”已经远远不够。

JEPA 方向最新进展

1. 严格时间增量为空，但最新排序补出了三个漏项

上次运行之后没有新的 arXiv 提交；今天的三篇主稿分别提交于 2026-07-30/31。这里把“提交时间”和“追踪首次发现”分开：它们可以是本系列新增，却不能写成今天发布。arXiv 最新排序

本轮排在它们之后的 CS-JEPA、JEPADepth、Rad-JEPA 3D、INTACT、Temporal-Distance JEPA、τ 与 LeapBot-WA 均已在既有记录覆盖，不重复汇报。

2. “预测 latent”正在分化成三种不同的下游接口

  • 决策检索键：Auto-JEPA 预测未来 ego trajectory latent，再检索 110,335 条真实轨迹中的 300 条候选；latent 本身不负责生成几何或验证安全。方法原文
  • 生成坐标系：MoRAE 先用 Motion-JEPA 学语义，再主动舍弃宽表示中的弱方向，并让 motion reconstruction gradient 塑造 decoder-compatible latent。方法原文
  • 科学表征对象：Physics-Aligned SSL 不改 I-JEPA 主目标，而是改变增强所声明的不变性，再看冻结/微调表示是否适合分类与物理回归。实验原文

三者说明“latent 有意义”至少要继续问：它是否适合检索、适合连续生成、适合物理量回归？这些性质不能互相替代。

3. 直接评估 JEPA 的负结果应与 JEPA 新方法同等保留

Physics-Aligned SSL 的价值不在于为 I-JEPA 刷榜，而在于提供 matched comparison：同一 ViT-B、同一单通道输入、相同数据与下游协议，仅改变 SSL objective 和 augmentation regime。结果中 I-JEPA 的物理增强收益较小，并且在 4D-STEM 上落后 scratch 与 MAE。

因此本系列把它归入“实际评估 JEPA 并用于下游”，而不是 related work；同时也不把整篇论文称为“I-JEPA 变体”，因为核心贡献是跨 SSL objective 的物理增强设计。

4. AquaJEPA 属于实际使用，但本日不挤入三篇主解读

AquaJEPA 来自 ITMO University，确实训练了 EMA target、动作条件 predictor、跨模态/物理辅助头，并在 Stonefish 水下机器人仿真中把预测交给统一 receding-horizon planner。它不是仅引用。

但其训练数据只有 12 段、每段 30 秒的仿真轨迹（8 train / 2 validation / 2 test）；预注册的主要比较对象 state-only 在 120 个 paired episodes 上 final-error 差为 -0.011 m，95% CI [-0.100, +0.079]，success 差为 +0.050，CI [-0.025, +0.125]，没有越过作者预设的主判定门槛。实验协议｜paired effects Table V

它对 ordinary multimodal、supervised dynamics 和 recurrent world model 的 paired final-error 改善均排除零，仍是值得保留的候选；但在无代码、无真机结果且主比较未决的情况下，本日优先解读证据更完整的三篇。

新增下游论文解读

1. Auto-JEPA: A Latent World Model of Continuous Intent for End-to-End Autonomous Driving

基本信息

  • 完整题目：Auto-JEPA: A Latent World Model of Continuous Intent for End-to-End Autonomous Driving
  • 作者：Jiwei Yang、Zhengxian Chen、Chaosheng Huang、Jun Li
  • 机构：当前 arXiv HTML 只保留作者后的机构编号 1/2，没有展开机构名称；官方代码仓也未补充。为避免用作者同名资料推断，本记录将机构标为“一手公开版本未列明”。
  • 时间与出处：arXiv:2607.29031 v1，2026-07-31 05:10:23 UTC；cs.RO / cs.AI 预印本，当前未见正式录用信息
  • 使用的 JEPA：冻结 V-JEPA 2 视觉 encoder，训练 24 层 Transformer predictor 去匹配冻结 trajectory encoder 产生的未来 ego-motion latent
  • 下游任务：NAVSIM v1/v2 的端到端自动驾驶轨迹规划
  • 复现状态：官方仓库 只有 5 个初始提交与项目骨架；README 明确说训练、检索、选择和评测代码仍在从研究工作区迁移

arXiv 元数据 · HTML 全文 · PDF

方法如何衔接 JEPA

可核对事实

  1. 先用 8 个二维 waypoint、4 秒 horizon 训练 trajectory autoencoder；encoder 输出 8×1024 target tokens，之后丢弃 decoder 并冻结 encoder。
  2. 输入为 4 张 256×256 前视相机历史帧、4 个历史 ego position 和 route command。冻结 V-JEPA 2 提取视觉 token，history/command encoder 与 24 层 predictor 输出对应未来时刻的 8 个 intent tokens。
  3. 训练损失是 normalized feature Smooth L1、逐 token cosine 与 batch-level InfoNCE 的加权和；它没有 I-JEPA/V-JEPA 标准的空间遮挡和 EMA target，target space 来自监督重建未来轨迹的冻结 autoencoder。
  4. 推理时以 predicted intent 检索 110,335 条 ground-truth trajectory memory 的 Top-300；CLOVER 初始化的 scene scorer 负责 collision、DAC、TTC、comfort、progress 排序，独立 gate 过滤 drivable-area 风险。

未来轨迹目标空间｜视觉意图预测｜检索与选择

作者主张

作者把 future ego motion 视为“场景中与未来动作相关信息”的压缩目标，认为不必生成完整视频、occupancy 或周围 agent 状态，也可以让模型关注真正影响规划的动态体。

本研究判断

它是广义、实际的 JEPA 下游系统，但不是 I-JEPA/V-JEPA objective 的原样复刻：视觉端复用 V-JEPA 2 checkpoint，目标端由带标签未来轨迹训练的 autoencoder 定义，还加入 InfoNCE 负例。最准确的描述是“V-JEPA 2 backbone + future-trajectory joint embedding prediction + retrieval planner”。

数据集、指标、主要基线与关键结果

数据与协议（事实）

  • NAVSIM v1：使用 trainval 训练，在完整 navtest 的 12,146 个 scenario 上报告 NC、DAC、TTC、comfort、ego progress 与 PDMS；
  • NAVSIM v2：按更新后的官方实现与 human-behavior filtering 报告 EPDMS；v1/v2 协议不同，不做跨版本换算；
  • scorer/gate 使用 75,823 个训练 scene、8,459 个验证 scene；memory 只含 NAVSIM training ground-truth trajectories；
  • trajectory AE 最多 40 epochs；intent predictor 10 epochs；一或两张 A100 80GB；主 benchmark 数字来自选定 checkpoint 的一次确定性完整评测，不是多次独立训练均值。

相对已有工作的创新

  1. 用连续未来轨迹 latent 代替离散驾驶意图类别和 dense future-world reconstruction；
  2. target encoder 与非参数 memory 共用同一轨迹空间，使预测 latent 可直接充当检索键；
  3. 把意图预测、轨迹实例化、scene utility 与 drivable-area feasibility 拆成四个可审计接口；
  4. 用动态体/随机等面积遮挡检查表示是否聚焦规划相关视觉区域。

局限、复现条件与潜在风险

  1. JEPA 独立归因不足。 没有 direct waypoint regression、相同 memory 的 no-InfoNCE/no-latent 对照，也没有 DINO/MAE/随机视觉 encoder 对照。
  2. 下游监督并非“无感知标签就无强监督”。 intent 分支不需要 box/occupancy，但 target 使用未来真实轨迹；scorer 还使用 collision、DAC、TTC、comfort 与 progress 离线标签。
  3. 非反应式评测。 NAVSIM 是 data-driven non-reactive benchmark，不能替代真实交通参与者会响应 ego action 的闭环道路测试。
  4. memory coverage 是硬上限。 Top-300 中没有可行 manoeuvre 时，scorer/gate 不能生成新轨迹；全部被 gate 拒绝时会退回未过滤排序。
  5. 统计有限。 主表只有一次选定 checkpoint 的确定性全量评测，没有独立训练 seed 或 checkpoint variation。
  6. v2 对 evaluator 版本敏感。 原实现为 85.6 EPDMS，更新后的官方实现和 human-behavior filtering 为 89.1；跨论文比较必须锁定 evaluator 版本。
  7. 代码尚未实际发布。 仓库有 MIT license 与目录规划，但训练和评测实现仍未迁入；暂不能复跑 91.3/89.1。
  8. 部署安全风险。 单前视相机、固定 memory 与 learned gate 在长尾天气、稀有交通规则、传感器故障和互动博弈下可能产生高置信错误。

复现判断：中低。 论文协议和超参数较完整，NAVSIM 可获得；但核心实现、模型权重、memory 构造与 scorer/gate 训练入口仍缺失。

2. MoRAE: Flow-Friendly Self-Supervised Latents for Text-to-Motion Generation

基本信息

  • 完整题目：MoRAE: Flow-Friendly Self-Supervised Latents for Text-to-Motion Generation
  • 作者/机构：Yifei Zhu、Yangyang Cai、Miao Cheng、Yoshifumi Kitamura（Tohoku University）；Mingyi Shi、Taku Komura（The University of Hong Kong）
  • 时间与出处：arXiv:2607.29180 v1，2026-07-31 09:01:25 UTC；cs.CV / cs.AI 预印本，当前未声明正式录用
  • 使用的 JEPA：从头训练 I-JEPA 式 Motion-JEPA：online encoder + predictor + EMA teacher，使用 temporal-span 与 joint-group masking
  • 下游任务：HumanML3D 与 KIT-ML 的文本到人体动作生成
  • 复现状态：官方项目仓库 当前只有 README，明确写明代码、预训练模型和使用说明“will be released”

arXiv 元数据 · HTML 全文 · PDF

方法如何衔接 JEPA

可核对事实

训练分三阶段：

  1. Motion-JEPA 从 masked motion 预测 clean motion 的 EMA-teacher feature，Smooth-L1 只作用于被遮位置；输出是 T×768 contextual features；
  2. 冻结 Motion-JEPA，用 variational encoder 压到 T×32；feature decoder 重建 JEPA feature，motion decoder 重建动作；motion loss 的梯度穿过两个 decoder 回到 compact encoder，形成 coupled geometry；
  3. 冻结 tokenizer，在 32 维 latent sequence 上训练 non-autoregressive flow-matching DiT；冻结 CLIP 编码文本条件，24 步 ODE 采样后解码为动作。

Motion-JEPA｜compact coupled tokenizer｜latent flow

作者主张

作者认为 motion latent 的生成难点有两个：协方差谱中大量弱方向让 Gaussian-to-data transport 不稳定；flow residual 若对齐 decoder 高敏感方向，即使 latent error 很小，也会放大成动作伪影。compact bottleneck 处理前者，motion-coupled training 处理后者。

本研究判断

MoRAE 的贡献不是“JEPA 直接生成得最好”，恰恰是证明原始 JEPA feature 不能直接当生成空间。JEPA 提供语义与结构，随后必须压缩、正则并按 decoder 后果重塑。这是对“强 representation 可直接复用”范式的一次有价值修正。

数据集、指标、主要基线与关键结果

数据与协议（事实）

  • HumanML3D 与 KIT-ML，20 FPS，使用 official split；
  • 主实验按 MARDM 使用 67 维 essential representation 及对应 evaluator；
  • 指标含 FID、R-Precision、Matching Distance、Multimodality、CLIP-style score、FootSkate、Jerk 与 Bone Variation；
  • DiT-XL 训练 800 epochs，batch 64，学习率 2×10^-4；24 步 probability-flow ODE；HumanML3D/KIT-ML 的 CFG 为 8.5/7.5；
  • 主表报告均值±误差；论文未在实验段说明误差定义、统计重复次数或独立训练 seed。

相对已有工作的创新

  1. 将 I-JEPA masked latent prediction 系统化移到人体动作时序，并同时遮时间片段与关节组；
  2. 不在宽 JEPA feature 上直接训练 flow，而是显式诊断谱条件数与 decoder Jacobian；
  3. 用可逆谱重参数化隔离“信息不变但 transport 变难”的因果效应；
  4. 让 motion reconstruction gradient 塑造 latent，使典型 flow error 避开 decoder 敏感方向；
  5. 在无需 VQ 或 autoregressive factorization 的情况下完成全序列生成。

局限、复现条件与潜在风险

  1. 公开仓库尚不可复现。 只有 README，无代码、配置、checkpoint、环境或训练日志。
  2. 训练统计不完整。 未报告表中误差的定义、统计重复次数、独立预训练/DiT seed、总 GPU 数、训练时长和能耗，不能据此判断训练方差。
  3. 协议依赖 MARDM evaluator。 67 维 essential representation 有利于物理解释，但与使用传统 263 维 evaluator 的论文不能直接横向换算。
  4. JEPA 不是唯一可能的语义 teacher。 有 no-SSL tokenizer，但没有同预算 MotionCLIP、contrastive motion encoder、MAE 或其他 SSL teacher 的 matched comparison。
  5. 只覆盖离线短动作数据。 没有长时序、多人/人—物交互、在线控制、物理模拟稳定性或真人偏好测试。
  6. 自动物理指标仍是代理。 FootSkate、Jerk、Bone Variation 不能完整代表接触、碰撞、自穿透与语义自然度。
  7. 生成滥用风险。 人体动作合成可用于动画与机器人，也可能被用于伪造行为、监控数据增强或不透明训练集扩充；发布模型时应记录数据许可与生成标识。

复现判断：中低。 数据集和算法描述清楚，但当前缺关键实现；即使复现框架，800-epoch DiT 与多阶段训练也需要不低算力。

是否值得改写成原创技术博客

值得，今天最高优先级。 推荐主题：

为什么“语义很强”的 JEPA latent，反而可能不适合 diffusion/flow 生成？

它能把 condition number、decoder pullback metric 与实际动作伪影串成一条清楚的机制线；同时要突出“JEPA 是源表示，MoRAE 的关键贡献是把它改造成生成坐标系”。

3. Physics-Aligned Self-Supervised Learning for Scientific Imaging

基本信息

  • 完整题目：Physics-Aligned Self-Supervised Learning for Scientific Imaging
  • 作者/机构：Bashir Kazimi、Stefan Sandfeld；Deep Learning for Electron Microscopy（DL4EM）group，Institute for Materials Data Science and Informatics（IAS-9），Forschungszentrum Jülich；RWTH Aachen University Chair of Materials Data Science and Materials Informatics
  • 时间与出处：arXiv:2607.28868 v1，2026-07-30 22:22:10 UTC；作者官方仓库标注为 GCPR 2026 论文并提供会议 citation；正式状态按作者仓库表述
  • 使用的 JEPA：在共享单通道 ViT-B backbone 下直接训练 I-JEPA，比较自然图像增强与 physics-aligned augmentation
  • 下游任务：NFFA 扫描电镜图像 10 类分类；模拟 LiNiO₂ 4D-STEM 衍射图的 quaternion crystal-orientation regression
  • 复现状态：官方代码、20 个预训练 encoder、Hugging Face 权重、精确 split manifests、运行脚本和 MIT license 均公开

方法如何衔接 JEPA

可核对事实

论文没有提出新的 JEPA predictor。它在 DINOv2、I-JEPA、MAE、SimCLR、VICRegL 五种方法上统一 ViT-B 与单通道输入，每种方法各训练两套：

  • T_orig：从自然图像 SSL 继承 crop、flip、blur、solarization 等增强；
  • T_phys：依据 measurement-consistent symmetry 与 acquisition perturbation，加入 90° rotation、gain/bias、Gaussian/Poisson noise、4D-STEM reciprocal-space scaling/tilt，去掉不符合物理的 flip/solarization。

因此它属于“直接评估 I-JEPA 的下游论文”，不是“只引用 JEPA”，也不是“新的 I-JEPA 架构”。augmentation pipeline

作者主张

作者认为 augmentation 不是普通数据增强，而是在声明模型应该对哪些测量变化保持不变；科学成像应先根据 measurement operator 枚举合法 symmetry 与 acquisition artifact，再用表示几何和单因素消融验证。

本研究判断

这篇论文最值得保留的是目标函数之间并不一致的结果：物理增强对 DINOv2/MAE 的部分任务帮助很大，对 I-JEPA 较小，对 SimCLR 甚至可能略降。它反对“同一组领域增强会普遍提高所有 SSL”，也说明 I-JEPA 的 masking/prediction bias 不会自动胜过 pixel reconstruction。

数据集、指标、主要基线与关键结果

数据与协议（事实）

  • CEM500K 预训练子集：10,000 train / 2,000 validation；
  • NFFA 下游：15,876 train / 2,116 validation / 3,177 test，10 类，报告三 seed mean±std；
  • 4D-STEM：10,000/2,000 预训练；232,531/29,067/29,067 下游 train/validation/test；图样由 Bloch-wave/py4DSTEM 模拟；
  • 下游包含 full finetune、linear probe、25% label finetune、gain/blur robustness；
  • 主要基线为共享 backbone 的 DINOv2、MAE、SimCLR、VICRegL 与 scratch。

相对已有工作的创新

  1. 把 scientific augmentation 明确定义为 measurement-consistent symmetry 与 acquisition perturbation 的并集；
  2. 在五个 SSL objective 上保持骨干、数据和非增强超参数一致，避免只展示单一方法的有利结果；
  3. 同时使用 full finetune、linear/low-label probe、物理回归与 acquisition robustness；
  4. 发布 20 个 encoder、精确 manifests、配置和逐表运行脚本，复现完整度高。

局限、复现条件与潜在风险

  1. 不是 JEPA 专项因果实验。 论文只改变 augmentation，没有隔离 I-JEPA mask 几何、target block 或 predictor 对科学任务的贡献。
  2. I-JEPA 证据总体偏弱。 full finetune 小幅提升，但 linear probe无改善，4D-STEM 仍输 scratch；不能据此推荐 I-JEPA 为该领域默认模型。
  3. 4D-STEM 是模拟数据。 Bloch-wave 模拟不能覆盖真实探测器漂移、样品缺陷、厚度误差和实验室差异。
  4. 领域范围窄。 只有 real-space EM 与 reciprocal-space 4D-STEM；不能直接外推到 MRI、遥感或天文成像。
  5. 增强仍含专家判断。 “物理合法”并不保证对任务标签无害；例如取向任务中的 rotation 与标签变换必须严格同步。
  6. 数据分布与类别不均衡。 NFFA 类别数量差异很大，单一随机 split 不能替代跨设备、跨实验室验证。
  7. 潜在误用。 科学图像模型若把模拟 artifact 当作真实不变性，可能在材料筛选或显微分析中形成系统性误差；部署应保留 calibration 与 human review。

复现判断：高。 数据来源、环境、config、权重、manifest 与命令齐全；主要障碍是下载数据和 GPU 训练成本，而不是实现缺失。

是否值得改写成原创技术博客

值得，中高优先级。 推荐主题：

科学图像的“数据增强”其实是在写物理假设：I-JEPA、MAE 与 DINOv2 为什么反应不同？

它适合做一篇证据审计型文章：不以 I-JEPA 胜出为卖点，而是讲清“匹配测量物理”与“选择 SSL objective”是两项独立决策。

三点横向判断：

  1. MoRAE 的机制归因最强。 它用可逆变换保持信息和 decoder 不变，能更直接说明谱条件数怎样破坏 flow；但“JEPA 相对其他 SSL teacher”的归因仍缺。
  2. Physics-Aligned SSL 的可复现性最高，也最能防止只报正结果。 I-JEPA 获得小幅 robustness 收益，却不是总体赢家；这类证据对选型比单一 leaderboard 更可靠。
  3. Auto-JEPA 的系统结果最接近决策应用，但组件混杂最大。 V-JEPA 2、未来轨迹 target、InfoNCE、memory、CLOVER scorer 与 gate 共同决定结果；需要更正交的消融才能归因。

值得继续追的问题

  1. Auto-JEPA 的收益来自哪里？ 固定 trajectory memory/scorer/gate，比较 direct waypoint regression、future-latent without InfoNCE、随机/MAE/DINO/V-JEPA 2 encoder。
  2. Auto-JEPA 能否脱离 ground-truth memory？ 测试 learned generator、local trajectory refinement 与 retrieval fallback，并画 memory coverage—PDMS—延迟曲线。
  3. 非反应式成绩能否迁移到互动闭环？ 在 CARLA/nuPlan reactive simulation 与真车 shadow mode 中检查他车响应、交通规则长尾和传感器故障。
  4. 动态体遮挡是否真在测 action relevance？ 使用 counterfactual rendering 或 object removal，保持背景/遮挡一致，区分“看见车辆”与“理解车辆影响”。
  5. MoRAE 的生成几何是否是 JEPA 独有？ 在同一 tokenizer/DiT 下替换 Motion-JEPA、MAE、contrastive motion SSL、supervised action encoder，并匹配参数与训练量。
  6. κ_flow 能否成为训练期可控目标？ 比较显式 spectrum regularization、whitening、low-rank bottleneck 与 coupled decoder，而不只在训练后诊断。
  7. decoder-aware alignment 能否推广到视频和机器人 action diffusion？ LeapBot-WA 的 ISAE 与 MoRAE 的 compact coupled tokenizer可做统一对照。
  8. HumanML3D/KIT-ML 的自动指标能否对应人类与物理判断？ 补 human preference、接触/自穿透模拟、长序列误差和文本组合泛化。
  9. 科学增强为何对 I-JEPA 收益小？ 正交改变 target block、mask ratio、旋转标签变换和 predictor 容量，检查是否是 I-JEPA 已通过 masking 获得了部分局部不变性。
  10. 4D-STEM 的 MAE 巨大优势能否在真实数据复现？ 需要跨显微镜、材料、探测器与实验室的外部测试，避免模拟器偏好 pixel reconstruction。
  11. AquaJEPA 的主要比较能否越过不确定区间？ 扩大独立训练 seed、真实水池试验和任务长度，公开代码/预注册材料，并与 state-only 做功效分析。
  12. Physics-Aligned 的 20 个 encoder 是否可做二次审计？ 复跑 manifests 与三 seed，核验类不均衡、split 稳定性和 robustness 统计，优先形成可复现实验博客。

博客价值判断

首选：MoRAE 的“好表示为什么不是好生成空间”

这是今天最适合主题化重写的材料。它把 JEPA、representation autoencoder、flow matching 和 decoder geometry 连在一起，并给出能被验证/证伪的两个机制量：κ_flow 与 residual–decoder alignment。

原创文章应避免写成“MoRAE 又刷了一个 SOTA”，而应围绕三步展开：

  1. 原始 JEPA feature 为什么语义好但谱很薄；
  2. compact bottleneck 为什么去掉弱方向；
  3. decoder-aware coupling 为什么比 reconstruction FID 更能预测生成质量。

次选：Auto-JEPA 的“latent 作为规划检索键”

适合与 Drive-JEPA、Temporal-Distance JEPA、INTACT 对照，讨论 latent 如何分别作为 future target、cost、inverse-action interface 与 retrieval key。必须把 scorer/gate 的 3.7 PDMS 贡献和单 checkpoint 限制写进主线。

反例型专题：Physics-Aligned SSL

适合写成“科学 AI 中，增强设计与 SSL objective 为什么不能捆绑选型”。I-JEPA 的弱/负结果、MAE 的强结果和完整公开复现材料，使它比单纯正向案例更有教育价值。

暂缓单篇：AquaJEPA

概念上值得追，但当前 state-only 主比较未决、训练轨迹极少且无真机/代码。除非作者公开预注册材料、实现或新版本，不建议独立成文。
