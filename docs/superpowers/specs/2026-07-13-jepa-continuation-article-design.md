# JEPA 延续追踪正式博客设计

## 目标

为个人技术博客撰写一篇 5000–7000 字左右的中文正式文章，追踪两篇 JEPA 后续工作：

- [LLM-JEPA: Large Language Models Meet Joint Embedding Predictive Architectures](https://arxiv.org/abs/2509.14252)
- [Value-Guided Action Planning with JEPA World Models](https://arxiv.org/abs/2601.00844)

文章承接已有博文《从 I-JEPA 到世界模型：一场算法对话的记录》，不重新长篇解释 JEPA 入门知识，而是回答一个更进一步的问题：当 JEPA 从视觉表征走向语言与行动规划时，它究竟发生了什么变化？

## 读者与文风

- 面向了解大模型或世界模型基本概念、但未必读过论文的技术读者。
- 采用“技术科普 + 深度观点”的正式博客文风。
- 保留关键公式、实现细节、实验数字和局限性，同时使用通俗比喻解释抽象概念。
- 不把两篇论文写成逐段摘要，而是围绕“可预测性与可规划性并不等价”形成完整论证。

## 标题与核心金句

标题：

> 能预测未来，不等于容易规划未来：JEPA 的两次延续

文章开头在引言之后用二级引用标题突出金句：

> ## 能预测未来，不等于容易规划未来。

结尾将其推进为：

> 能预测未来，是世界模型的起点；能在未来里找到一条路，才是规划的开始。

## 核心叙事

文章采用一条连续演化线，而不是两篇论文并排介绍：

```text
I-JEPA：在表示空间预测
    ↓
LLM-JEPA：让语言的两种表达在表示空间对齐
    ↓
Value-Guided JEPA：让表示空间不仅可预测，而且可规划
```

中心判断是：JEPA 不只是一种固定架构，更像一种研究偏好——放弃对原始信号每个细节的重建，把学习压力放到抽象表示及其关系上。但“表示可被预测”只是必要条件；要支持行动规划，表示空间的几何结构还必须与任务价值一致。

## 文章结构

### 1. 从上一站继续出发

简短链接并回顾旧文：I-JEPA 的关键转向，是从像素重建改为表示空间预测。随后抛出本文问题：同一思想进入语言和控制后，`Predictor` 是否还是同一件事？

### 2. 第一条延续：LLM-JEPA 把“同一语义的两种表达”拉到一起

以自然语言描述与代码实现为双视图，解释训练目标：

```text
L = L_NTP + λ · [1 - cos(Pred(Enc(Text)), Enc(Code))]
```

重点说明：

- 论文中的 `Pred` 不是独立世界模型，而是追加在同一个 LLM 输入末尾的若干 `[PRED]` 特殊 token；最后一个预测 token 的隐藏状态负责逼近目标序列表示。
- JEPA 分支只参与训练，推理时丢弃，因此它更接近一种表示正则化，而不是新增推理模块。
- 自回归的 next-token prediction 仍然是锚点。论文附录显示，仅用 JEPA 目标会产生空输出；公开实现也没有经典 I-JEPA 的 EMA target encoder 或 stop-gradient target branch。
- 报告代表性结果，同时提醒训练开销、超参数选择与预训练规模仍有限。

本节结论：LLM-JEPA 的贡献不在于让 LLM 真正“模拟未来”，而在于要求语言模型学到跨表述方式更稳定的语义几何。

### 3. 转折：预测得准，为什么仍然可能走不出去

用“隔墙很近、绕路很远”的迷宫比喻解释问题：标准 JEPA 只要求预测后的表示接近真实下一状态，却没有保证表示空间中的直线距离能反映达到目标的行动代价。因此，一个预测准确的世界模型仍可能给规划器一张错误的地图。

这一节集中展示核心金句，并把文章从表示学习推向决策问题。

### 4. 第二条延续：用价值函数塑造可以规划的表示空间

介绍行动条件世界模型：

```text
z_t = E(s_t)
ẑ_{t+1} = Pred(z_t, a_t)
```

说明这里的 `Pred` 是独立 MLP，而且在推理阶段被 MPC/MPPI 反复调用，与 LLM-JEPA 的训练辅助分支完全不同。

随后解释价值引导的核心：让目标条件价值等于表示空间距离的负值，借助 IQL/expectile TD 学习，使“距离目标更近”在表示空间里具有决策意义。重点写出：

- 普通欧氏距离版本与 quasi-distance 版本的差异。
- 最佳方案不是把预测损失和价值损失强行联合训练，而是先用价值目标塑造/冻结编码器，再训练动力学预测器。
- 代表性结果：相较最佳标准 JEPA 基线，WS 从 0.55 到 0.71，WB 从 0.89 到 0.96，Maze 从 0.54 到 0.63。
- 证据边界：实验仍是二维墙体和迷宫环境，缺少多随机种子误差条、预测精度、延迟和计算量报告，因此结论应写成“展示了方向”，而非“解决了通用规划”。

### 5. 三个 Predictor，其实是三种角色

用对照表消除术语混淆：

| 工作 | Predictor 的输入输出 | 是否独立模块 | 推理时是否保留 | 主要作用 |
| --- | --- | --- | --- | --- |
| I-JEPA | 上下文表示 → 被遮挡区域表示 | 是 | 下游通常不保留 | 学表征 |
| LLM-JEPA | 文本表示 → 代码/目标表示 | 否，依托同一 LLM 的 `[PRED]` token | 否 | 训练期语义对齐 |
| Value-Guided JEPA | 当前状态表示 + 动作 → 下一状态表示 | 是 | 是 | 世界模型滚动与规划 |

强调：论文都使用 JEPA 词汇，不代表 `Predictor` 在系统中的工程职责相同。

### 6. 更深一层：世界模型需要“目的塑造的几何”

形成文章的观点段落：

1. 可预测性关注模型能否复现环境变化。
2. 可规划性关注优化器能否利用这种表示找到有效动作。
3. 决策需要的不只是事实压缩，还需要与价值、可达性和控制代价一致的空间结构。

把两篇论文联系起来：LLM-JEPA 说明辅助预测目标可以重塑语义表示；Value-Guided JEPA 进一步说明，表示空间最终长成什么样，取决于你要求它服务什么目标。

### 7. 结语

回到 I-JEPA → LLM-JEPA → Value-Guided JEPA 的演进，明确这些工作还不是一条已经完成的统一路线，而是共同把 JEPA 从“预测什么”推进到“为了什么而预测”。最后以推进后的金句收束。
