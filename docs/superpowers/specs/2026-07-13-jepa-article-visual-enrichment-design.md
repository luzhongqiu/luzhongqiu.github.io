# JEPA 延续追踪文章视觉增强设计

## 目标

将已发布文章《能预测未来，不等于容易规划未来：JEPA 的两次延续》从纯文字技术长文升级为图文并茂的解释型文章。插图必须帮助读者理解概念关系，而不是单纯装饰页面。

本文档覆盖并替代原设计中“不增加图片资产”的约束，其余标题、论点、证据边界和文章篇幅要求保持不变。

## 方案选择

考虑三种路线：

1. 直接引用论文图：实现快，但两篇论文视觉风格不统一，裁切、清晰度和版权标注增加维护成本。
2. 只制作艺术封面：能改善首屏，但无法解释 `[PRED]`、潜空间几何和 MPC 等技术难点。
3. 制作原创技术插图：工作量较高，但能准确配合本文叙事，并与博客已有 JEPA 图形保持一致。

采用方案 3。所有图片均为本地 SVG，避免外链失效，保证桌面端和移动端清晰。

## 统一视觉语言

- 画布使用 `viewBox="0 0 720 ..."`，与现有 JEPA 插图的 720px 正文宽度一致。
- 白色或极浅灰背景，圆角卡片，使用系统字体。
- 蓝色表示 Encoder/表示学习，黄色表示 Predictor/预测，红色表示目标或阻塞，绿色表示价值引导/可行路径，紫色表示规划器。
- 图内文字只保留关键词和一句解释，详细论述留在正文。
- 箭头、虚线、图例语义保持一致；不依赖外部字体、脚本和图片。
- 每张图在正文中使用居中 `<img>`，提供准确的 `alt` 与简短图注。

## 插图设计

### 1. JEPA 演进总览

文件：`source/img/jepa/jepa-evolution-map.svg`

位置：开篇核心金句和三段文本流程之后。

内容：用三张连续卡片展示 I-JEPA、LLM-JEPA、Value-Guided JEPA。每张卡片分别突出“被遮挡区域表示”“另一种语言表达”“带动作代价的未来”，底部用一条从“可预测”到“可规划”的渐进轴收束。

目的：让读者在进入细节前获得整篇文章的路线图。

### 2. LLM-JEPA 训练与推理分流

文件：`source/img/jepa/llm-jepa-training-inference.svg`

位置：解释 `[PRED]` token 和推理阶段移除 JEPA 分支之后。

内容：上半部分画训练期双目标：自然语言输入经过同一 LLM，一路做 NTP 生成，一路通过 `[PRED]` hidden state 与目标序列表示做 cosine 对齐；下半部分画推理期只保留普通自回归生成，并明确标记“JEPA branch removed”。

目的：直观消除“`Pred` 是独立世界模型”“JEPA 替代了 NTP”两个常见误解。

### 3. 可预测不等于可规划

文件：`source/img/jepa/predictable-vs-plannable.svg`

位置：“从预测到规划，中间隔着一堵墙”章节的迷宫例子之后。

内容：左右对照。左侧普通 latent distance 把墙两侧状态画得很近，红色直线被墙阻断；右侧 value-shaped distance 将合法绕行路径画成绿色梯度，表现“先远离目标，再到达目标”。

目的：把全文核心金句转化为一眼可懂的空间关系。

### 4. Value-Guided MPC 闭环

文件：`source/img/jepa/value-guided-planning-loop.svg`

位置：分阶段训练与规划流程说明之后、实验结果表格之前。

内容：当前状态经 Encoder 得到 latent，Predictor 对多组候选动作 rollout，quasi-distance/value 为候选未来评分，MPPI 选出第一步动作，执行后重新观察并回到起点。图角落补充“Encoder 先由 value 塑形，再冻结训练 Predictor”。

目的：说明 Predictor 在第二篇论文中是推理期真正运行的动力学模型，并展示规划闭环。

## 验证标准

- 四个 SVG 均为合法 XML，可由浏览器直接打开。
- 图片在 720px 桌面宽度和窄屏下均不溢出；正文统一设置 `width="720"` 或更小。
- 每张图片都有非空 `alt`，且文章引用路径存在。
- Hexo 构建成功并生成目标文章页面。
- 生成 HTML 中存在 4 个本地图片路径、核心金句和两篇论文链接。
- 不提交或修改 `source/_drafts/` 下现有草稿。
