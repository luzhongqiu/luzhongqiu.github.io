## JEPA 方向最新进展

### 1. “预测单元”开始由领域结构决定

- I-JEPA 预测图像 patch；BioM-JEPA 把目标改成 STRING protein-association / corpus coexpression 图上的 connected gene blocks，并对 block 内 teacher token 先聚合、再计算 latent prediction loss。[方法图与定义](https://arxiv.org/html/2608.05928v1#S0.F1)
- Bar-JEPA 沿用 I-JEPA multi-block prediction，但修改输入打包以接受保持宽高比的可变分辨率图表，说明预测目标不变时，输入几何接口也会决定下游可用性。[变量分辨率设计](https://arxiv.org/html/2608.06062v1#S3.F3)
- PhyLatent 保留 LeWM 式未来 latent prediction，却额外约束“同物理状态应不变、不同物理状态应可辨、不同动作未来应分离”，把控制所需的等价类直接写入训练目标。[框架](https://arxiv.org/html/2608.05720v1#S4.F3)

这三篇共同说明：JEPA 的关键词已不只是“预测 latent 而非像素”，而是**什么构成一个可预测目标、哪些变化应被视为不变量、predictor 最终由谁消费**。

### 2. Predictor 生命周期出现三种分化

- **BioM-JEPA**：预训练结束后冻结 encoder，丢弃 predictor；下游统一读取 1,536 维 cell embedding。
- **Bar-JEPA**：同样只保留 context encoder；冻结 encoder 后训练热图 decoder。
- **PhyLatent**：部署时移除五类辅助 head，但保留 action-conditioned predictor 和 MPC planner。

这使三篇论文的证据不能混成一个排行榜：前两篇主要测试 frozen representation，后一篇测试 predictor-conditioned control。

### 3. 严格区分“实际使用”与“只引用”

#### 实际使用、但本日未占用主解读名额

- [SR-JEPA: Learning Predictive Latent State in 3D Scenes](https://arxiv.org/html/2608.05774v1)：从头训练 point-native EMA target / context encoder / sparse predictor；在删除完整物体后，以固定 32-point、无形状 query 查询缺失实体 latent。ARKitScenes 5,953 个 held-out objects 上 semantic identity macro accuracy `43.13%`，比最强 shortcut floor 高 `22.18` 点；Sr3D support AP `41.15`。它是严格截止后新稿且证据控制精细，但任务仍依赖 **oracle target centroid**，只覆盖静态场景；object discovery、动作、时序转移、rollout 和 planning 均未验证，故本轮先作为高价值 predictor-diagnostic 候选。
- [HERA: Historical Evidence Routing Adapter for Physical Prediction in Latent World Models](https://arxiv.org/html/2608.05523v1)：冻结 V-JEPA 2-G encoders 和 predictor blocks，只训练 3.00M 参数的 structured memory / memory registers / workspace registers。在 IntPhys2 Main 的 506 对 possible–impossible videos 上，pairwise AvgSurprise accuracy `52.57→54.35%`；固定相机 immutability 子组 `46.15→63.46%`。它不是 related-work 引用，但提交早于截止；正文只说多 seed，未披露 seed 数、误差条或总体显著性，也没有代码入口，且总体仍接近 chance，暂不主解读。
- [Helping Music Co-Creation Agents ‘Listen’ Well](https://arxiv.org/html/2608.04378v1)：实际训练 2.55M 参数 JEPA-style Swin V2，并接 probing、flow matching、inpainting；仍需完成数据切分、matched baseline、生成评测与代码/权重审计。
- [SJEPA](https://arxiv.org/html/2608.04060v1)：实际使用 EMA target 和 symbolic/neural transition，但下游限于二维摆与人工 grammar，无稳定代码入口。
- [FactorJEPA](https://arxiv.org/abs/2608.01049)：实际修改 V-JEPA 2.1 并评估 DENSEWORLD 城市视频；headline 仍以内部 future-latent 指标为主，闭环任务边界待审。
- [EEG-JEPA](https://arxiv.org/abs/2608.00114)、[HP-JEPA](https://arxiv.org/abs/2608.00491)：分别覆盖 EEG-FM-Bench 与图分类/回归，均是早于本轮窗口的真实 JEPA 候选。

#### 不计入具体 JEPA 下游证据

- [Discrete energy as an exact label-free training objective for finite-element surrogates](https://arxiv.org/abs/2608.05437) 是 FE-JEPA programme 的理论 note；当前稿给出与 JEPA pretraining 相关的条件命题和反例，但没有一个已实现、可评估的 JEPA 下游系统，不计入今天主论文。
- 仅在引言/related work 中讨论 I-JEPA、V-JEPA、LeJEPA，方法、checkpoint、predictor 或训练 objective 均未进入实验的命中，继续排除。

## 新增下游论文解读

### 1. BioM-JEPA: joint-embedding prediction of graph-connected gene blocks in single cells

#### 元数据

- **完整题目**：*BioM-JEPA: joint-embedding prediction of graph-connected gene blocks in single cells*
- **作者**：Yuhao Wang、Zelin Zang、Yuxuan Liu、Zhen Lei、Stan Z. Li。
- **机构**：Westlake University；香港中科院人工智能与机器人研究中心（CAIR, HKISI-CAS）；中国科学院自动化研究所多模态人工智能系统全国重点实验室；中国科学院大学。
- **时间与出处**：arXiv:2608.05928 v1，2026-08-06 11:58:29 UTC；当前是预印本，未见会议/期刊接收声明。[提交历史](https://arxiv.org/abs/2608.05928)

#### 它实际使用了哪种 JEPA

这是从 I-JEPA 抽象出发、面向稀疏单细胞转录组重新定义 target 的真正 JEPA 方法，不是把普通 encoder 改名：

1. student 接收一名细胞中除目标 block 外的已观测基因；
2. 共享 12 层、768 维 linear-attention 架构的 EMA teacher 接收完整已观测基因；
3. 目标 block 来自 STRING protein-association 图或无标签 corpus coexpression 图的 connected expansion；
4. 对 block 中当前可观测的 teacher gene states 做 aggregate，四层 predictor 从 context 预测该 block 表示；
5. block alignment 与预测表示的统计正则共同训练，teacher stop-gradient；没有逐基因 input reconstruction objective。[正文方法](https://arxiv.org/html/2608.05928v1#S3.SS4)

预训练后丢弃 predictor，冻结 encoder，把每个基因 token 的 feature-wise maximum 与每维 top-5 mean 拼接成 1,536 维 cell embedding，供所有下游任务使用。[embedding 定义](https://arxiv.org/html/2608.05928v1#S3.SS7)

#### 下游任务、数据、指标与基线（事实）

- **预训练暴露**：本地 collection 有 22.1M cells；主分析 checkpoint 经历 10.24M cell presentations，相当于 scBaseCount 502M-cell 资源的 `2.04%` presentation-equivalent。这里应写“presentations”，不能偷换成 10.24M 个唯一细胞。[预训练说明](https://arxiv.org/html/2608.05928v1#S3.SS8)
- **few-shot cell annotation**：CellBench-LS 的 PBMC12k、hPancreas、cortex、MS、liver、Zheng68k、lung、COVID、immune 共 9 个数据集；Top-5 few-shot macro-F1/accuracy/recall，五固定 seed。
- **frozen-embedding reconstruction**：其中 8 个数据集；共享 decoder 预测 canonical expression vector，评价 cell-wise Pearson、nRMSE、high-expression gene recovery、Reactome programme correlation 和 15-NN graph overlap。
- **perturbation response**：Adamson、Norman、Dixit；control-cell embedding + perturbation identity 预测 perturbed expression，指标包括 MSE-LFC、MSE-Expr、Pearson-LFC、sign、Top-50 response-gene overlap；表中可共同对比的 Adamson/Norman 结果用五 seed。
- **表示诊断/生物分析**：effective rank、participation ratio、embedding leading axis/norm 与 detected-gene count 的相关，以及 pancreas marker programmes、programme ablation、directed block dependencies、Norman double-perturbation composition。
- **matched objective controls**：same vocabulary、encoder width、linear-attention backbone、downstream extraction 的 token-IJEPA、random block、decoder-only。
- **foundation-model baselines**：UMAP、scVI、CellPLM、Geneformer、LangCell、scGPT、scMulan、scFoundation、Nicheformer。[完整 benchmark 表](https://arxiv.org/html/2608.05928v1#A3.T7)

#### 关键结果

**事实（表格可直接核对）**：

- 在 hPancreas + cortex 的同骨干 objective-family 对照中，BioM-JEPA Top-5 macro-F1 均值为 `0.835`，高于 token-IJEPA `0.817`、random block `0.812`、decoder-only `0.797`。[Figure 3](https://arxiv.org/html/2608.05928v1#S1.F3)
- 在更广的 9 数据集、10 模型 frozen probe 中，BioM-JEPA mean macro-F1 是 `61.62%`（95% dataset bootstrap CI `51.56–71.94`，mean rank `4.33`）；Nicheformer `67.30%`、scFoundation `66.17%`、CellPLM `65.27%`。BioM-JEPA **不是 annotation SOTA**。[Table S7](https://arxiv.org/html/2608.05928v1#A3.T7)
- Adamson perturbation 表中，BioM-JEPA 的 Top1/5/9 MSE-LFC 为 `14.887±0.171 / 14.381±0.076 / 14.801±0.080`，三者平均 `14.694`；MSE-Expr 平均 `0.194`，八个 error cell 均列 `1/9`。Norman 对应 MSE-LFC 均值 `6.188`、MSE-Expr 均值 `0.082`，同样均为 `1/9`。[Table S12](https://arxiv.org/html/2608.05928v1#A3.T12)
- 单 A100-SXM4-80GB、batch 8、相近 trainable parameters 下，BioM-JEPA / scFoundation 的 partial fine-tuning throughput 为 `24.37 / 4.24 cells·s⁻¹`（`5.75×`），held-out embedding throughput `62.78 / 16.68`（`3.76×`）；peak memory `27.98 / 24.59 GiB`，因此速度更快但显存并不更低。[Table 1](https://arxiv.org/html/2608.05928v1#S1.T1)

**作者主张**：

- block prediction 没有把表征压成狭窄的类别 code；frozen representation 在 8 数据集平均 expression/pathway/neighbourhood recovery 上最强，并在 perturbation aggregate error 上最优。[Figure 4](https://arxiv.org/html/2608.05928v1#S1.F4)、[Figure 5](https://arxiv.org/html/2608.05928v1#S1.F5)
- graph-connected gene blocks 是把 JEPA 扩展到 molecular data 的有效 prediction unit；linear attention 让更宽的 observed-gene context 可计算。

**本次推断**：

- 同骨干 controls 支持“完整 BioM-JEPA formulation 优于三种替代 formulation”，但不能把增益单独归因于 graph connectivity、aggregate target 或 regularizer 中某一个组件，因为作者明确说明 controls 比较的是 complete formulations。
- 广泛 annotation 未领先而 perturbation/error 指标领先，提示 block objective 更可能保留连续 programme/response structure，而非单纯强化 cell-type decision boundary；这是一条值得复现的任务依赖假设，不是论文已经证明的普遍规律。
- 速度优势主要来自 linear attention 与 scFoundation dense architecture 的系统差异，不等于 JEPA objective 天生更快。

#### 创新、局限、复现条件与风险

- **创新**：首次把 graph-connected gene-block aggregate 表示作为 JEPA target；把 prediction unit 从单 gene 提升到 operational programme-like block；同时保留 matched objective family 与跨模型 benchmark。
- **最关键风险：预训练—评测重叠不可排除**。442 个 matrix-only shards 没有 study accession/source manifest；所有 benchmark 原始研究都早于 2025-02-25 pretraining cutoff，因此本套 benchmark 不是 temporal holdout。作者只能保证未使用 benchmark labels/splits，不能保证未见过同研究细胞。[overlap audit](https://arxiv.org/html/2608.05928v1#A2.SS2.SSS3)
- graph-connected blocks 只是 operational target，不自动等于 curated biological pathway；coexpression graph 从无标签 matrices 估计，也受相同 accession 不可审计问题影响。
- depth association 只检查 leading embedding axis 和 embedding norm；不能据此宣称移除了全部测序深度/批次混杂。
- 官方只承诺“will be released via GitHub”；当前没有可核验训练代码/checkpoint。arXiv ancillary 有 panel-level numerical source data，但不分发 count matrices、per-cell embeddings 或 full predictions。[数据/代码声明](https://arxiv.org/html/2608.05928v1#S5)
- 复现需要 scBaseCount 派生数据、固定 graph/vocabulary、单细胞预处理、至少 A100 80GB 级硬件；在代码尚未发布前，只能复核数字和协议，不能复跑训练。

#### 是否值得单独写原创博客

**很值得。** 最好的主题不是“JEPA 打败单细胞 foundation models”，而是：**预测 gene 还是预测 programme？预测单元如何决定 JEPA 学到的生物结构**。文章应把 `0.835` matched-control 结果与 `61.62%` 非 SOTA broad benchmark 同时放在标题以下，形成诚实的证据张力。

### 2. Bar-JEPA: Extracting Values from Bar Chart with Joint-Embedding Predictive Architecture

#### 元数据

- **完整题目**：*Bar-JEPA: Extracting Values from Bar Chart with Joint-Embedding Predictive Architecture*
- **作者/机构**：Poonam Poonam、Alexander Epple、Timo Ropinski；Ulm University（由作者官方仓库论文说明核验）。
- **时间与出处**：arXiv:2608.06062 v1，2026-08-06 14:07:26 UTC；论文注释和官方 citation 均标为 **ICDAR 2026 accepted / in proceedings**。[arXiv](https://arxiv.org/abs/2608.06062)、[官方仓库](https://github.com/epplea/Bar-JEPA)

#### 它如何衔接 I-JEPA

1. 从原始 I-JEPA 官方 ImageNet-1K ViT-H/14 300-epoch checkpoint 初始化；
2. 在 100k 无标签合成 bar charts 上继续训练 50 epochs，仍采用 context encoder、EMA target encoder、narrow predictor 和 multi-block latent prediction；
3. 将图像 resize/patch packing 改成 Pix2Struct 式 aspect-ratio-preserving、最多 256 个 14px patches，以支持可变宽高比；
4. 下游丢弃 target encoder 与 predictor，冻结 context encoder；classic/simple decoder 只读取 feature map，回归 bar tops、ticks、origin 热图，再与 PaddleOCR tick labels 组合恢复数值。[方法与训练](https://arxiv.org/html/2608.06062v1#S3)

这属于“直接复用并领域继续训练 I-JEPA”，不是 JEPA-style 泛称。

#### 下游任务、数据、指标与基线（事实）

- **任务**：vertical bar chart de-rendering / per-bar numerical value recovery。
- **encoder 自监督训练**：100k 合成 charts；一组实验再在 15k Chart-to-Text real-world charts 上继续 25 epochs。
- **decoder 监督训练**：17k 合成 charts、50 epochs；再用 UB PMC / ICPR CHART-Infographics 2022 中 1,316 个有需要标签的 vertical charts 做 30 epochs finetuning，训练/验证为 80:20。
- **最终测试**：100 个专门生成的 synthetic charts；UB PMC split 4 中 139 个具备所需标签的 vertical charts。
- **指标**：bar F1、tick F1；相对值误差阈值 `ε=0.05` 的 relaxed accuracy 与 `ε=0.02` 的 hard accuracy。keypoint matching 用 Hungarian algorithm，位置阈值约 `2.3%`。
- **内部 controls**：同一 I-JEPA ViT-H 起点下的 variable resolution、fixed resolution、未做 chart JEPA 的 vanilla ImageNet I-JEPA、simple decoder、额外 real-world encoder finetuning、oracle OCR。
- **外部参考**：Soto 等 chart element detection、Zhou 等 value recovery；但测试集不同，论文自己明确说只能 conceptual comparison，不能视为严格 matched baseline。[实验协议](https://arxiv.org/html/2608.06062v1#S4)

#### 关键结果

**事实（同表内部可比）**：

- UB PMC：real-world FT 的 bar/tick F1 为 `0.785/0.842`，relaxed/hard accuracy `0.499/0.365`；variable resolution 为 `0.740/0.827`、`0.450/0.341`；fixed resolution 为 `0.716/0.812`、`0.422/0.292`；vanilla 为 `0.161/0.024`、`0/0`。[Table 1](https://arxiv.org/html/2608.06062v1#S4.T1)
- synthetic：real-world FT 为 `0.961/0.951`、`0.792/0.657`；variable resolution `0.956/0.940`、`0.778/0.629`；fixed resolution `0.882/0.892`、`0.654/0.498`；vanilla `0.389/0.182`、`0.056/0.051`。
- OCR 并非当前主要瓶颈：UB PMC oracle OCR relaxed/hard `0.512/0.389`，只比 real-world FT 的 `0.499/0.365` 小幅提高。
- classic decoder 是 load-bearing component：simple decoder 在 UB PMC relaxed/hard 只有 `0.009/0.005`，synthetic `0.014/0.006`。因此结果不是“任意轻量 head 都能读出 I-JEPA”。
- 与外部工作的非同集参考：本文 synthetic relaxed accuracy `79%`，Zhou `82%`；real-world `50%`，Zhou `71%`。元素 F1 则本文 synthetic/real-world `0.956/0.814`，Soto `0.981/0.555`。[Table 3/4](https://arxiv.org/html/2608.06062v1#S4.T3)

**作者主张**：

- self-supervised chart-domain I-JEPA finetuning 产生更适合 chart value recovery 的 semantic features；变量分辨率以几乎无额外成本改善宽高比变化；相对既有 supervised pipeline，decoder 更快收敛、标签需求较少。

**本次推断**：

- vanilla 与 fixed-resolution 的差异明确证明“领域继续训练有效”，但没有 MAE/DINO/普通 masked feature prediction 的同数据同骨干对照，不能把增益唯一归因于 JEPA objective；它也可能是 100k chart-domain exposure 的收益。
- variable-resolution 是第二个独立增益源，decoder capacity 是第三个。不能把完整 `0→0.422` relaxed accuracy 都写成 JEPA 的贡献。
- 139 张 real test 太小，且没有多 seed/置信区间；`0.499` 不应被描述为成熟的生产级 chart extraction。

#### 创新、局限、复现条件与风险

- **创新**：首个明确把 I-JEPA 用于 chart de-rendering 的工作；提供 aspect-ratio-preserving I-JEPA 输入；公开 100k synthetic generator/dataset。
- **范围限制**：方法只研究 vertical、unstacked bars；生成器不含 error bars、3D effects 等。作者也明确承认模型简单、非 SOTA、目前不适合直接接多模态 LLM 做 chart QA。[Discussion](https://arxiv.org/html/2608.06062v1#S5)
- **数据限制**：real test 只有 139 张；外部 baselines 使用不同 test sets/thresholds，不能做严格排名。
- **系统依赖**：ViT-H 较大，OCR 与 postprocessing 仍是完整 pipeline 的组成部分；simple decoder 失败说明“轻量 decoder”表述需要限定为 classic deconvolution head。
- **复现条件**：官方仓库公开训练/评测代码、结果 CSV/confusion matrices、Hugging Face synthetic datasets 与 checkpoints；I-JEPA base checkpoint 需另放入指定路径。pixi 配置注明 CUDA 12.1 Windows、MPS macOS、Linux 暂不支持；也提供 PyTorch≥2.3 的 pip 安装路径，并依赖 PaddleOCR。[仓库 Setup/Data/Checkpoints](https://github.com/epplea/Bar-JEPA)

#### 是否值得单独写原创博客

**值得，优先级中高。** 适合写成一篇可复现案例：**把通用 I-JEPA 变成图表读数器，真正起作用的是领域自监督、宽高比处理还是 decoder？** 文章应突出 `vanilla→fixed→variable→real-world FT` 的逐级证据，并诚实放入 139 张 test、无 matched alternative SSL 和非 SOTA 的边界。

### 3. PhyLatent: Learning Dynamics-Relevant Representations for JEPA World Models

#### 元数据

- **完整题目**：*PhyLatent: Learning Dynamics-Relevant Representations for JEPA World Models*
- **作者**：Xi Zeng、Haojie Ren、Ziying Song。
- **机构**：Nanyang Technological University School of Mechanical and Aerospace Engineering；Yanshan University School of Artificial Intelligence (School of Software)；The University of Sheffield。
- **时间与出处**：arXiv:2608.05720 v1，2026-08-06 08:02:15 UTC；当前预印本，未见会议/期刊接收信息。[提交历史](https://arxiv.org/abs/2608.05720)

#### 它如何衔接 JEPA

PhyLatent 直接沿用 LeWorldModel 风格的 action-conditioned encoder–predictor、EMA target 与 SIGReg baseline，并在同一预测图上添加五个训练期组件：

- **SVIC**：static visual invariance，让不改变 simulator state 的外观增强保持 latent 接近；
- **PSG**：physical state grounding，以 simulator-derived current physical targets 监督 encoded/predicted latents；
- **FRA**：future representation alignment；
- **CASC**：counterfactual action separation，把不同 action branch 的 predicted futures 拉开；
- **LD**：latent denoising，正则局部 future geometry。

这些 auxiliary heads 在部署时删除；视觉 encoder、action encoder、predictor 与 MPC planner 保留。[方法总览](https://arxiv.org/html/2608.05720v1#S4)

#### 下游任务、数据、指标与基线（事实）

- **任务/数据**：stable-worldmodel 接口的 OGBench-Cube（2,010,000 transitions / 10,000 episodes）、TwoRooms（920,809 / 10,000）、DMC Reacher（2,010,000 / 10,000）、PushT（2,336,736 / 18,685）；各自 90:10 random train/validation split。[Table 2](https://arxiv.org/html/2608.05720v1#S5.T2)
- **MPC protocol**：每个 rollout 从 dataset state 初始化，目标取同 trajectory 25 steps 后的 state；最多 50 environment steps；每个模型 3 seeds × 100 episodes。planner prediction/receding horizon 均为 5，每步 100 candidate sequences、top-10 elites。
- **表示诊断**：Cube 上 physical invariance failure（1,000 states）、identifiability collision（200,000 state pairs）、counterfactual branch failure（1,000 action pairs），均三 seed。
- **baseline**：相同 architecture / planner 的 `JEPA + SIGReg`。ViT-Tiny/14 从头训练、latent 192，predictor 6 blocks；完整训练图约 19.6M trainable parameters。
- **资源**：单 RTX 5080、bfloat16；Cube / TwoRooms / Reacher / PushT 训练约 `14h35m / 3h32m / 19h02m / 32h43m`。[实现细节](https://arxiv.org/html/2608.05720v1#S5.SS2)

#### 关键结果

**事实**：

- Cube 三类 failure rate：JEPA+SIGReg 的 `15.60 / 6.71 / 8.41%` 降为 `7.53 / 0.95 / 4.62%`；MPC success `70.00±4.00→78.10±2.80%`。[Table 5](https://arxiv.org/html/2608.05720v1#S5.T5)
- TwoRooms `81.00±6.24→98.00±1.00%`；Reacher `78.33±2.08→79.33±3.51%`；PushT **下降** `77.67±0.58→75.33±2.08%`。[Table 4](https://arxiv.org/html/2608.05720v1#S5.T4)
- Cube grouped ablation：去 PSG+FRA 后 success `74.00±1.00%`；去 SVIC `77.00±1.00%`；去 CASC+LD `73.33±3.51%`；完整 `78.10±2.80%`。CASC+LD removal 对 planning drop 最大，但 ablation 一次移除一组，仍不能区分组内两个组件。

**作者主张**：

- SIGReg 只维持 aggregate latent distribution 的 global non-collapse，不能保证局部物理等价类、状态可辨识性与动作反事实分支；PhyLatent 把这些结构显式写入训练目标，产生更可靠的 MPC state space。
- Cube 与 TwoRooms 的增益说明相同 representation principles 同时适用于 manipulation 与 navigation；Reacher/PushT 被描述为“remains comparable”。

**本次推断**：

- Cube/TwoRooms 支持“在本协议中，额外物理结构监督改善控制”，但不支持“纯 JEPA 自监督本身学出物理结构”，因为 PSG 使用 simulator-derived privileged targets。
- PushT 的 latent diagnostics 也改善、MPC 却退化，说明作者提出的 failure rates 不是控制成功的充分统计量；contact-rich local transition 与 planner cost 仍可能主导。这是论文最有价值的反例之一。[PushT 分析](https://arxiv.org/html/2608.05720v1#A3.SS3)
- 只有 `JEPA+SIGReg` 一个 matched baseline，未与 Temporal Straightening、Temporal-Distance JEPA、TC-LeWM、ProWorld 或 supervised state model 做同协议比较；不能判断五目标方案是不是最简/最优解。

#### 创新、局限、复现条件与风险

- **创新**：把 global collapse 拆成 physical invariance / identifiability / counterfactual dynamics 三个可测 failure mode，并使每类 diagnosis 对应训练 constraint；部署不增加 auxiliary heads。
- **privileged supervision**：PSG 需要 simulator physical state。Appendix Table 7 说明不含 future state、success label 或 terminal indicator，但仍限制了在真实、无 state instrumentation 场景的可用性。[Table 7](https://arxiv.org/html/2608.05720v1#A2.T7)
- **归因混合**：五个 objective 与 task-specific weights 同时变化；group ablation 未覆盖逐组件、matched-compute 或 alternative regularizer。
- **外推限制**：四个视觉仿真任务、单 planner；无真实机器人、视觉域移、partial observability、长 horizon 或 action noise 评估。
- **统计限制**：三 seeds × 100 episodes，论文未报告 pairwise significance；Reacher 差异小于跨 seed variability，PushT 反向。
- **复现状态**：论文给出架构、loss weights、augmentations、training time 和 datasets，但 arXiv v1 正文/附录未提供代码、checkpoint 或项目仓库 URL；当前只能按文字重实现。

#### 是否值得单独写原创博客

**值得，但更适合主题化横向文章，而不是只复述 headline。** 建议主题：**JEPA 不坍塌，为什么仍不是好控制状态？** 可把 PhyLatent 与 TC-LeWM、Temporal Straightening、Temporal-Distance JEPA、ProWorld 串成一篇“global distribution、local geometry、planner cost”三层失配的原创文章。若写单篇，应把 simulator state supervision 与 PushT 退化放进摘要。

## 横向比较

| 维度 | BioM-JEPA | Bar-JEPA | PhyLatent |
|---|---|---|---|
| JEPA 血缘 | I-JEPA 式 EMA teacher/student，重定义 gene-block target | 直接使用官方 I-JEPA ViT-H checkpoint 并领域继续训练 | LeWM 式 action-conditioned JEPA + SIGReg |
| Predictor 生命周期 | 训练后丢弃 | 训练后丢弃 | MPC 时保留，auxiliary heads 丢弃 |
| 具体下游 | cell annotation、expression/pathway reconstruction、perturbation response | bar/tick detection、数值恢复 | Cube/TwoRooms/Reacher/PushT MPC |
| 最强机制证据 | same-backbone token/random/reconstruction controls | same I-JEPA 起点的 vanilla/fixed/variable/real FT 阶梯 | same architecture/planner baseline + grouped ablation |
| 最强反证 | broad annotation 不及 Nicheformer/scFoundation | real-world relaxed accuracy 49.9%，非 SOTA；simple decoder 几乎失败 | PushT 成功率下降；Reacher 增益很小 |
| 主要混杂 | block graph、aggregation、regularizer；可能 pretrain overlap | domain data、variable resolution、decoder capacity | simulator state supervision、五辅助目标、task-specific weights |
| 复现状态 | 数字齐全，代码/checkpoint 尚未发布 | 代码、数据、checkpoint、结果公开 | 无公开代码/权重入口 |
| 今日价值 | 最高：新领域 prediction unit + 正反证完整 | 最高复现价值：具体 I-JEPA 应用 | 最高控制机制价值：non-collapse ≠ controllability |

不能横向比较三篇的绝对分数；它们的数据、指标和 predictor 生命周期完全不同。真正可比的是研究设计：是否有同骨干对照、是否把系统增益拆开、是否公开反例与复现入口。

## 值得继续追的问题

1. **BioM-JEPA overlap audit**：代码发布后能否用 accession-resolved、真正 temporal holdout 的单细胞数据重跑？如果消除潜在 pretraining overlap，perturbation 优势还保留多少？
2. **预测单元消融**：固定相同 block sizes、regularizer 和 aggregation，只把 STRING / coexpression / random adjacency 逐一替换，才能回答“生物图”是否 load-bearing。
3. **Bar-JEPA matched SSL**：同 ViT-H、同 100k charts、同 50 epochs 比 I-JEPA、MAE、DINO/self-distillation 与监督 chart pretraining；否则只能确认领域继续训练有效。
4. **Bar-JEPA small-test uncertainty**：139 张 UB PMC test 应给 bootstrap interval，并做 chart-source / stacked / error-bar / clutter 分层。
5. **PhyLatent 去 privileged state**：可否用 optical flow、keypoint tracks、inverse dynamics 或 foundation-model pseudo-state 替代 simulator state，并保持 Cube/TwoRooms 增益？
6. **PushT 反例**：为什么三类 failure rates 都降低却 MPC success 下降？需要把 contact transition error、cost calibration、candidate coverage 与 latent geometry 分开测。
7. **SR-JEPA predictor 接口**：去掉 oracle target centroid，接入 object proposal/discovery 后 `43.13%` identity completion 和 `41.15 AP` 能保留多少？
8. **HERA 总体不确定性**：公开 seed-level results、paired confidence interval 与代码后，再判断 `+1.78pp` 是否稳健；子组结果还需考虑多重比较。
9. **A-JEPA / 音频线**：下一轮继续深审 Helping Music 的生成评测与数据切分；本轮无新的 A-JEPA direct-use 投稿。
